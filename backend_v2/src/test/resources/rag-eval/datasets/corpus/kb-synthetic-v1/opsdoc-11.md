# 堡垒机使用手册

本文档为企业内部知识库文档，供员工与系统检索使用。

## 操作步骤

1. 登录星澜工作台并进入堡垒机
- 操作：在浏览器访问星澜工作台，通过内部系统单点登录完成身份认证，在应用列表中选择“堡垒机”。
- 验证点：登录后页面右上角显示本人工号与所属部门；内部系统单点登录会话时长为 8 小时，超时后必须重新认证才能继续操作。
- 占位：【截图占位：星澜工作台应用列表 — 堡垒机入口】

2. 核对账号与密码有效期
- 操作：进入“个人设置—安全”，查看当前账号的密码状态与剩余有效天数。账号密码每 90 天强制更换一次，系统会在到期前提示更换，请在提示出现后及时完成修改。
- 验证点：密码状态显示为“有效”；若显示“即将过期”或“已过期”，须先完成密码更换，再返回堡垒机继续后续步骤。
- 占位：【截图占位：安全设置页 — 密码有效期与状态】

3. 申请目标主机授权
- 操作：在堡垒机“资产管理”中检索目标主机，提交授权申请，填写使用事由与预计使用时长，提交给所属业务线负责人审批。
- 验证点：申请单状态变为“已通过”，且“我的资产”列表中出现该主机；未通过或待审批状态下一律不可连接。
- 占位：【截图占位：授权申请单 — 审批状态】

4. 连接目标主机
- 操作：在“我的资产”中点击目标主机右侧的“连接”，按提示选择协议与登录方式，复制系统生成的连接命令在本地终端执行。
- 验证点：终端回显连接成功信息，并显示本次会话编号；会话编号需记录在变更单或工单中，便于后续追溯。
- 命令示例占位：
```
ssh -p <堡垒机端口> <工号>@<堡垒机地址>
```

5. 执行操作与会话留痕
- 操作：连接成功后按授权范围执行运维操作，涉及高危命令时按系统提示填写二次确认说明。
- 验证点：页面或终端提示会话处于“录制中”状态；操作结束后可在“会话审计”中按会话编号检索到对应审计记录。
- 占位：【截图占位：会话审计 — 录制状态与审计记录】

6. 结束会话并填写备注
- 操作：操作完成后输入退出命令或点击“断开连接”，在弹出窗口中填写本次操作摘要与结果。
- 验证点：会话列表状态变为“已结束”，录像文件生成完成且可正常回放；备注为空时不允许提交。
- 命令示例占位：
```
exit
```

7. 异常处理
- 操作：若出现无法连接、认证失败或会话中断，记录会话编号与报错提示文本，提交工单至运维值班。
- 验证点：工单提交成功并获得工单号；在问题闭环前不得改用其他账号或绕过堡垒机直连目标主机。

## 附录：检查清单

本清单用于堡垒机操作前后的自查，适用于所有通过堡垒机登录生产环境的运维与研发人员。每次操作前逐项确认，操作后逐项复核；异常项须在工单中记录并上报运维值班。

**一、执行前核对项**

1. 账号与权限：使用本人账号登录，不得共享或借用；确认已满足账号密码每 90 天强制更换一次的要求，密码临近到期或已过期时先完成更换再登录；确认本次操作所需主机与账号均在授权范围内，临时授权须附工单编号。
2. 会话与身份：内部系统单点登录会话时长为 8 小时，登录前确认当前会话未超时，也未使用他人遗留会话；离开工位须锁屏或主动断开连接。
3. 变更与窗口：确认变更已在星澜工作台提交并获批，操作处于约定维护窗口内，回滚方案与责任人明确。
4. 目标与环境：核对目标主机名、IP、环境（生产/测试）三项信息是否一致，避免误连；确认操作命令清单已评审。
5. 录屏与审计：确认会话录屏、命令审计处于开启状态，禁止关闭或绕过审计通道。
6. 批量与自动化：通过脚本或接口批量操作时，确认调用量在 API 网关默认限流为每客户端 200 QPS 之内，超限须提前申请并分批执行。

**二、执行后核对项**

1. 结果验证：按操作清单逐项确认执行结果，检查服务状态、日志与关键指标是否恢复正常。
2. 会话收尾：主动退出堡垒机会话并断开连接，确认无挂起会话；临时账号与临时授权及时回收。
3. 变更记录：在工单中填写执行时间、操作内容、结果与异常，附必要截图或审计记录编号。
4. 审计核对：核对本次会话录屏与命令记录已完整入库，发现缺失立即上报。
5. 异常上报：出现越权访问、误操作或审计告警，第一时间上报运维值班与安全负责人，不得自行删除记录。
6. 定期复查：账号密码每 90 天强制更换一次、单点登录会话时长为 8 小时等策略以星澜工作台实际配置为准，每季度核对一次策略生效情况。

## 回滚方案

本节适用于堡垒机版本升级、策略模板调整、双因子与单点登录对接配置变更等操作。任何回滚均须由堡垒机管理员在星澜工作台提交变更单，经运维负责人审批后执行，不得由个人在未登记的情况下直接恢复配置。

**一、回滚触发条件**

变更发布后出现下列任一情况，应立即启动回滚，不必等待完整复现与定责：

1. 运维人员无法通过堡垒机登录，或登录成功率明显下降，导致生产资源无法正常接入；
2. 单点登录对接异常，内部系统单点登录会话时长为 8 小时的策略无法生效，或用户被异常登出、反复要求重新认证；
3. 双因子认证、账号密码策略失效，或出现账号可绕过认证直接登录的情况；
4. 审计能力受损，会话录像、命令日志缺失或不完整，无法满足审计留存要求；
5. 权限策略误拦截正常运维操作，且短时间内无法定位原因；
6. 出现越权风险，例如普通运维账号可见或可连接高权限资产。

**二、回滚步骤**

1. 冻结变更：在星澜工作台将变更单状态置为“回滚中”，暂停后续发布批次，禁止继续修改堡垒机配置。
2. 保留现场：导出当前配置快照与审计日志，记录变更前后的配置差异，作为后续复盘的依据。
3. 恢复版本：依据变更单记录回滚至上一稳定版本；若为策略类变更，则将策略集整体回滚至上一版本，避免逐条手工修改引入新的偏差。
4. 恢复认证配置：回滚过程中如需重置账号，须遵循账号密码每 90 天强制更换一次的要求，不得为图省事设置长期口令或多人共享账号。
5. 同步信息：在运维沟通群同步回滚原因、影响范围与当前进度，并通知受影响的业务团队。
6. 记录归档：回滚完成后在变更单中填写触发原因、执行人、执行时间与回滚版本号。

**三、回滚后验证**

1. 登录验证：分别抽测管理员账号与普通运维账号，确认可正常登录并接入授权资产。
2. 单点登录验证：确认从星澜工作台单点登录进入堡垒机流程正常，会话时长仍为 8 小时，并能按预期到期失效。
3. 资产连通性验证：抽查主机、数据库等资产的协议代理与连接链路，确认无连接超时或认证失败。
4. 审计验证：确认会话录像与命令日志正常写入，可按人员、资产、时间检索。
5. 权限验证：核对角色与资产授权同回滚前基线一致，未出现越权可见或越权操作。
6. 策略验证：确认双因子认证与密码有效期策略（含 90 天强制更换）均已生效。

验证通过并持续观察运行状态无异常后，方可关闭变更单；若回滚后问题仍未消除，应升级至运维负责人，评估二次回滚或临时停机方案，并在恢复服务前完成书面记录。

## 审核时效

**一、操作审批时效**

堡垒机所有运维操作均须先申请、后执行，审批链路与工单流转统一在星澜工作台内完成，不接受口头、即时通讯工具或邮件形式的独立授权。

- **提交要求**：申请人须在工单中写明目标资产、操作类型、操作范围、执行窗口与回滚方案。信息不全的工单由审批人直接退回，退回后须重新提交，重新计时。
- **分级受理**：工单按风险等级排队。涉及生产环境写入、配置变更、批量数据操作的工单，由资产归属团队负责人与运维值班负责人共同审批；只读类查询工单由资产归属团队负责人单人审批。审批人须在当班期间处理待办工单，不得积压至交班后。
- **超时处理**：工单超过当班未处理的，由星澜工作台自动升级提醒至审批人上级；升级后仍未处理的，工单自动关闭，申请人须重新发起。已关闭工单不得复用。
- **放行校验**：审批通过后，堡垒机在建立连接前校验账号状态。账号密码每 90 天强制更换一次，密码逾期未更换的账号一律不予放行，须先完成更换再重新提交申请。
- **会话时限**：审批通过的运维会话纳入内部系统单点登录会话管理，内部系统单点登录会话时长为 8 小时；会话达到该时长后自动中断，需继续操作的须重新登录并重新触发审批，不得以延长会话方式绕过审核。

**二、应急免审批条件**

免审批通道仅用于遏制正在扩大的生产事故，不作为提效手段。

- **适用情形**：生产环境整体或核心链路不可用、数据面临丢失风险、安全事件需立即阻断，且按正常审批流程处理将显著扩大影响的，可启动应急免审批。
- **不适用情形**：日常变更发布、批量数据导出、权限提升与授权调整、账号新增等，一律不得以应急名义免审批。
- **执行要求**：须取得运维值班负责人明确授权，至少两名具备相应权限的人员同时在场，操作全程开启会话录屏并保留命令记录；操作范围严格限定在与故障处置直接相关的资产与指令内，不得顺带执行其他变更。
- **事后补单**：应急处置结束后须立即在星澜工作台补交工单，注明免审批原因、授权人、参与人与实际操作记录，由运维值班负责人复核确认。未按要求补单或复核不通过的，暂停该账号堡垒机权限并按内部流程处理。

## 适用场景

**触发条件**

出现下列任一情形时，须通过堡垒机接入目标资源，不得从办公终端直连：

1. 运维人员需要登录生产环境服务器（含北京总部机房与上海研发中心机房）、生产数据库或网络设备，执行查看、配置、发布、回滚等操作。
2. 外部厂商或临时协作人员需要远程接入生产环境进行排障、部署或联调。
3. 需要执行临时提权、批量脚本或高风险变更，须留存完整操作会话以备审计回溯。
4. 发生安全事件或故障复盘，需要调阅历史会话录像与命令记录。

**影响范围**

1. 人员范围：运维、研发、测试及经审批的外部协作人员，在访问生产环境时均适用。
2. 资源范围：星澜工作台与星澜云控制台中登记的生产主机、数据库实例、网络设备及跳板资源。
3. 认证范围：堡垒机统一使用星澜工作台账号登录，内部系统单点登录会话时长为 8 小时，超时后须重新认证方可继续操作，未完成的会话将被中断。
4. 不在本范围：办公网普通业务系统与非生产测试环境按原有流程访问；程序化调用经 API 网关发起、不经过堡垒机，仍按 API 网关默认限流为每客户端 200 QPS 执行。

**前置检查**

1. 账号与授权：确认星澜工作台账号处于启用状态，且已在堡垒机中完成目标资源的授权绑定。
2. 密码有效期：账号密码每 90 天强制更换一次，登录前请确认密码未过期；临近到期或已过期的，先在星澜工作台完成更换再接入。
3. 审批单据：涉及生产变更、临时提权或外部人员接入的，须先取得已审批通过的工单或变更单，并在登录时填写对应单号。
4. 客户端与环境：确认所用终端已安装公司规定的安全客户端，网络可达堡垒机接入地址，多因素认证已绑定并可正常接收验证。
5. 会话准备：明确操作目标与回滚方案，需要录屏留档的高风险操作应提前在工单中说明。
