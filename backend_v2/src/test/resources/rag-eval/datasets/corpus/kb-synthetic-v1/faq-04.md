# 工牌与门禁 FAQ

本文档为企业内部知识库文档，供员工与系统检索使用。

## 解决步骤

遇到工牌无法刷卡或工牌遗失时，请按以下编号步骤处理，每一步都给出预期结果与失败时的检查点。

1. 确认故障范围。在故障门禁点连续刷卡两次，并换一处门禁点（如办公区入口与会议室走廊）复测。预期结果：明确故障属于单张工牌失效、单个门禁点异常，还是多个门禁点同时不可用。失败时的检查点：若两次刷卡均无任何提示音、指示灯也不亮，先确认该门禁点是否通电、读卡器指示灯是否正常，再进入第 2 步。

2. 在星澜工作台提交工牌报修或补办申请。填写工号、姓名、所属部门、失效现象与发生时间；遗失情形需勾选“挂失”。预期结果：提交成功后系统生成工单号，并显示受理状态。失败时的检查点：确认登录账号为本人账号、必填项填写完整；若页面提示附件格式不符，请重新选择文件后再提交。

3. 按工单提示补交材料。需要补交工牌照片或身份证明扫描件时，通过企业邮箱发送至工单指定的受理地址，并在正文注明工单号。预期结果：材料被受理，工单状态更新为“制卡中”。失败时的检查点：企业邮箱单个附件上限为 50MB，附件超限会导致投递失败，请压缩或拆分后再发送；同时确认邮件正文中的工单号与申请记录一致。

4. 等待制卡完成。工牌补办周期为 3 个工作日，自工单状态变为“制卡中”之日起计算。预期结果：在 3 个工作日内收到领取通知，通知中包含领取地点与领取时间段。失败时的检查点：超过 3 个工作日仍未收到通知，凭工单号在星澜工作台查询进度；若状态长期停留在“待受理”，请联系本部门行政对接人核实。

5. 领取并激活新工牌。到通知指定地点出示本人工号或有效身份证件领取，领取后立即在办公区入口门禁点刷卡验证。预期结果：刷卡成功，门禁正常开启，指示灯与提示音正常。失败时的检查点：若新工牌仍无法开启门禁，回到第 2 步以“新卡无法激活”重新提交工单，并在描述中附上原工单号。

6. 完成旧卡处置。若为换卡或遗失补办，领取新卡时交回旧卡；遗失情形需在工单中确认挂失已生效。预期结果：旧工牌权限被停用，工单状态更新为“已完成”。失败时的检查点：若旧卡仍在手中但权限已被停用，请勿自行反复刷卡，交由行政统一回收处理。

处理期间如需临时进出，请走前台登记通道，不要借用他人工牌。全部步骤完成后，建议在星澜工作台确认工单已关闭，便于后续追溯。

## 无法解决时

**无法解决时怎么办**

如果按照前面的自助排查步骤仍无法解决，请不要重复提交相同内容的工单，直接按下面的升级路径提交，以便问题进入更高一级的处理队列。

**升级路径**

1. 一线受理：在星澜工作台提交 IT 支持工单，事项类型选择「门禁与工牌」，并填写工号、所在办公地点（北京总部或上海研发中心）、门禁点位或闸机编号、问题首次出现时间。
2. 二线升级：工单在一线未解决时，由服务台转至 IT 运维二线继续处理；你也可以在工单中回复「申请升级」，由服务台执行转派，无需另开新工单。
3. 三线升级：涉及门禁控制器、权限系统数据异常等需现场处理的情况，由二线转派三线工程师并协调园区物业；如对处理结果有异议，可在工单内申请升级至 IT 服务负责人复核。
4. 紧急通道：若因工牌失效或门禁故障无法进入办公区，请直接联系所在办公地点前台，并同时提供工单号，前台将协调临时通行。

**提交材料与附件要求**

请在工单中上传门禁报错提示截图、工牌照片或闸机现场照片，便于定位。通过企业邮箱补充材料时，请注意企业邮箱单个附件上限为 50MB，超出请压缩后上传或分多封邮件发送。

**响应时效承诺**

- 工单提交后，服务台按工单系统中显示的受理与响应时效承诺执行；具体承诺时间以工单页面展示为准，升级不会重置已累计的等待时间。
- 工牌补办周期为 3 个工作日，自工单审核通过且信息核对无误之日起计算；补办期间如需进出办公区，可按上述紧急通道申请临时通行。
- 升级后请保持工单中登记的联系方式畅通，处理进展与结论统一在工单内回填；如超过承诺时效仍未收到响应，请在工单中回复「超时催办」，服务台将优先跟进。

## 问题描述

本部分汇总员工在星澜工作台提交工牌与门禁类工单时最常见的原始提问方式，并说明这些提问通常发生在什么场景，便于同事在自助检索时快速对号入座，减少重复提问。

**一、用户原始问法**

员工提交工单或咨询时，通常不会使用“工牌挂失与门禁权限变更”这类规范表述，而是直接描述现象，常见问法包括：

- “工牌丢了怎么办？怎么挂失？补办要多久能拿到？”
- “昨天提交的补卡申请，今天能做好吗？我明天要进公司。”
- “新入职员工的工牌什么时候发？没有工牌能不能先进办公区？”
- “工牌消磁了、刷不开闸机，是不是要重新办一张？”
- “我调到上海研发中心了，原来的工牌还能用吗？门禁要重新开吗？”
- “我需要进另一个楼层的办公区，刷不开门，找谁开通权限？”
- “离职当天工牌要交回吗？交到哪？”
- “工牌找到了，之前挂失的那张还能恢复使用吗？”

**二、发生场景**

上述问法集中在以下几类场景中：

1. 新员工入职首日：尚未领取工牌，或临时工牌已过期，需要确认领卡时间与临时通行方式。
2. 工牌遗失、被盗或损坏：员工发现无法刷卡进门、无法在食堂与打印设备上使用工牌时，第一时间发起咨询。
3. 补办进度催问：员工提交补办申请后希望尽快拿到新卡。需要注意的是，工牌补办周期为 3 个工作日，但仍有不少同事在提交当天或次日就来追问进度，此类咨询可按周期口径答复。
4. 组织与地点变动：员工转岗、跨部门协作或调往上海研发中心，原有门禁权限不再覆盖实际办公区域。
5. 权限范围不足：员工因项目需要进入本人权限之外的办公区域，刷卡时闸机提示无效，需要走权限申请流程。
6. 离职与交接：员工办理离职手续时需归还工牌，并对门禁权限做停用确认。
7. 挂失后找回：员工在挂失后又找回原卡，希望确认旧卡是否可继续使用。

如你的情况属于以上任一场景，可先按对应条目查阅后续解答；若仍无法判断，请在星澜工作台提交工单，并写明工牌编号、所在办公地点与具体现象，便于快速定位处理。

## 注意事项

**一、权限要求**

- 工牌申领、补办与门禁权限开通均须通过星澜工作台提交申请，经直属主管审批后流转至行政与信息安全团队处理；未提交申请或审批未通过的，不予办理。
- 办公区常规门禁由直属主管审批即可；机房、财务档案室等受限区域须由部门负责人与信息安全团队双重审批，并在申请单中写明进入事由与使用频次。
- 委托他人代办时，须在申请单中注明代办人并附授权说明；代办人不得代领后转交未登记人员使用。
- 访客与外包人员的门禁权限由接待部门代为申请，权限范围与可访问时段以申请单为准，不得口头扩大。

**二、时效限制**

- 工牌补办周期为 3 个工作日，自申请审批通过之日起计算，制卡完成后由行政通知本人领取。
- 临时凭证仅在补办期间有效，正式工牌领取后须当场交回临时凭证。
- 门禁权限的新增、调整与回收，均在审批通过后按流程生效；员工离职或转岗时，原权限由系统统一回收，不保留延续使用。
- 挂失即时生效，挂失后原工牌不可再刷卡进入任何区域。

**三、易错点**

- 工牌转借他人：工牌与个人身份绑定，转借、代刷均属违规，门禁记录一律关联至持卡人本人。
- 遗失后未及时挂失：应在发现遗失后第一时间在星澜工作台提交挂失，未挂失期间产生的门禁记录由持卡人负责。
- 尾随进入受限区域：执行一人一刷，不得为他人开门或尾随进入机房等受限区域。
- 信息填写不合规：申领时提交的证件照与工号信息须与人事档案一致，信息不符会导致制卡被退回并重新计算办理时间。
- 临时权限到期未续期：设有有效期的临时权限到期后自动失效，需重新提交申请，不可口头延期。
