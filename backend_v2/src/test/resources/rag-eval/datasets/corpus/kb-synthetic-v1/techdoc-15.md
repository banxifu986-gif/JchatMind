# CDN 配置与管理

本文档为企业内部知识库文档，供员工与系统检索使用。

## 概述

本概述说明星澜科技 CDN 配置与管理能力的定位、依赖关系与适用范围，供负责域名加速配置的运维人员与研发人员在接入前对齐认知。

**服务定位**

CDN 配置与管理是星澜云控制台提供的统一配置入口，负责加速域名从创建、配置、变更到下线的全生命周期管理。使用者在一处维护源站地址、缓存规则、回源策略与访问控制，配置保存后由平台下发至边缘节点，避免在多套系统间重复填写造成不一致。该能力服务于内部系统与对外服务的加速需求，不替代源站自身的容量与可用性建设。

**依赖组件**

- 星澜云控制台的账号与权限校验：配置操作按角色授权，未授权操作在提交阶段即被拒绝。
- 域名与证书配置：加速域名需先完成归属确认与证书绑定，之后才能下发配置。
- 源站信息：包括源站地址与健康检查结果，源站不可用时配置不予生效，并提示失败原因。
- 日志服务：访问日志与操作日志统一采集，日志在线保留 30 天，归档保留 365 天，请按此周期安排问题排查与审计取证。
- 星澜工作台的检索能力：搜索服务索引刷新延迟不超过 5 秒，配置项与变更记录提交后稍作等待即可检索到。

**适用场景**

- 静态资源加速：页面脚本、样式、图片等静态文件就近分发。
- 大文件与安装包下载：降低源站带宽压力，改善跨地域下载体验。
- 跨地域访问优化：总部、上海研发中心及外部用户访问同一服务时的链路优化。
- 流量波动应对：活动或发布期间的访问峰值由缓存层承接，回源量保持在可控范围。
- 灰度与回滚：按域名或规则维度调整配置，出现异常时回退至上一版本。

以上场景均通过星澜云控制台完成配置，具体操作步骤与管理规范参见后续章节。

## 变更流程

CDN 配置变更指对星澜云控制台中 CDN 加速域名、缓存策略、回源规则、证书与访问控制等配置项的任何修改。所有变更须经申请、审批、执行、验证四个环节，禁止在生产环境直接调试。

**变更申请**

申请人须在星澜工作台提交变更单，写明变更域名、变更类型（缓存规则 / 回源配置 / 证书更新 / 访问控制）、变更前后的配置差异、影响范围与预计影响时长、验证方案及回滚预案。涉及证书更新或回源地址调整的，须附灰度验证结果。未填写回滚预案的变更单不予受理。常规变更须至少提前 1 个工作日提交；紧急变更可走加急通道，但须在变更单中说明紧急原因。

**审批链路**

审批按影响范围分级：

1. 一般配置变更（缓存 TTL、响应头等）：申请人直属主管审批后即可执行。
2. 影响核心域名的变更（回源规则、证书、访问控制）：经直属主管审批后，转由 CDN 平台负责人复核，再由运维值班负责人批准，共三级。
3. 涉及多域名批量变更或预计影响时长超过 30 分钟的变更：在上述三级之外，须增加业务方负责人会签。

审批全部通过后变更单状态变为“可执行”，申请人在约定窗口内于星澜云控制台实施。变更单与操作记录一并留存：日志在线保留 30 天，归档保留 365 天，审计时以归档记录为准。

**回滚方式**

每次变更前须在控制台导出并保存当前生效配置作为回滚基线，回滚基线随变更单归档。

- 配置级回滚：变更后验证不通过时，在星澜云控制台选择对应域名的历史配置版本一键回退，回退操作须在变更单中登记时间与操作人。
- 分步回滚：批量变更按域名逐个回退，每回退一个域名即验证一次，确认正常后再处理下一个。
- 证书类变更回滚：保留原证书至少 7 个工作日，回滚时重新绑定原证书并复核 HTTPS 握手是否正常。

回滚完成后须在星澜工作台更新变更单状态为“已回滚”，记录失败现象与初步原因。变更后验证包含配置生效确认与访问验证；若变更涉及与搜索服务联动的缓存策略，验证时须确认搜索服务索引刷新延迟不超过 5 秒，超出该阈值的按验证失败处理并立即回滚。

## 错误码与排查

在星澜云控制台的 CDN 服务中，边缘节点返回的失败请求都会带有统一格式的错误码。排查任何故障前，请先确认域名处于「已启用」状态，并准备好域名、错误码、发生时间与请求 traceid，以便定位与留证。

**CDN-4031 回源鉴权失败**

现象：边缘节点请求源站被拒绝，用户侧收到 403 响应。

处置：核对源站鉴权密钥与签名时间戳算法是否一致，确认密钥仍在有效期内；在星澜云控制台「CDN > 域名 > 回源配置」中重新保存密钥，等待配置下发完成后再次验证；若仍失败，导出该时段的访问日志并提交工单。

**CDN-4042 缓存键冲突**

现象：携带不同查询参数的请求命中同一缓存对象，返回内容与预期不符。

处置：检查缓存键是否包含业务必需的查询参数与请求头；修改缓存键规则后，先在低流量域名验证，再全量下发；对已污染的路径执行缓存刷新，并在刷新后复测。

**CDN-5023 回源超时**

现象：边缘节点与源站建连或读取超时，用户侧收到 504 响应。

处置：确认源站健康状态与安全组放通情况；评估回源超时阈值是否匹配接口实际耗时，对动态接口设置为不缓存并单独配置较长超时；观察失败是否集中于单一机房或单一源站，必要时切换回源线路。

**CDN-5210 证书校验失败**

现象：HTTPS 握手失败，或终端提示证书不受信任。

处置：确认证书链完整、域名匹配且未过期；在星澜云控制台重新上传证书并绑定至对应域名；启用强制 HTTPS 前先验证 HTTP 可正常回源，避免配置后无法回退。

**CDN-5301 配置未生效**

现象：配置保存成功，但线上行为与预期不一致。

处置：确认配置处于「已下发」状态；在星澜工作台检索本次变更记录，注意搜索服务索引刷新延迟不超过 5 秒，可稍候重试检索；随后清理本地 DNS 与浏览器缓存，并使用不同网络复测。

**通用排查与留证**

所有访问日志与操作日志统一在星澜云控制台查询：日志在线保留 30 天，归档保留 365 天。超出在线窗口的日志须从归档中检索，因此建议在故障发生后的 30 天内完成关键日志的导出与归档。提交工单时请附上域名、错误码、请求时间、traceid 以及已执行的排查步骤，便于快速定位。

## 接入流程

本流程适用于在星澜云控制台为业务域名开通 CDN 加速。整个接入过程分为前置申请、配置项说明与联调验证三个阶段，请按顺序执行；任一阶段未通过，不得进入下一阶段。

**一、前置申请**

1. 在星澜工作台提交「CDN 接入申请」工单，写明业务归属团队、加速域名、预期上线时间与对接人。
2. 加速域名须已完成 ICP 备案，且备案主体与申请主体一致；未备案域名不予受理。
3. 在工单中提供源站信息：源站类型（自建机房、云主机或对象存储）、源站地址、回源协议与回源端口。
4. 如需 HTTPS 加速，须同时提交有效期内的证书与私钥，或在星澜云控制台申请托管证书。
5. 工单由业务负责人与运维负责人审批后，由运维在星澜云控制台创建加速域名并回填工单。

**二、配置项说明**

- 加速域名：全局唯一，创建后不可修改；如需变更，请新建加速域名并重新走接入流程。
- 源站配置：支持主备源站；主源站不可用时自动切换至备源站，请确保备源站与主源站内容一致。
- 缓存规则：按目录或文件后缀配置缓存策略，动态接口须显式设置为不缓存。
- 缓存过期时间：按资源更新频率分级设置，更新频繁的资源应配置较短的过期时间。
- 回源 Host：默认与加速域名一致；源站按域名区分站点时，必须显式指定回源 Host。
- 访问控制：按需配置 IP 黑白名单、Referer 防盗链与 URL 鉴权，鉴权密钥由运维统一下发。
- 日志：CDN 访问日志默认开启，日志在线保留 30 天，归档保留 365 天；如需更长期留存，请在归档期内自行下载至对象存储。

**三、联调验证**

1. 使用测试域名或 hosts 绑定方式验证，确认解析已生效、回源链路可达。
2. 使用 curl 等工具检查响应头中的缓存命中标识，确认首次回源、二次命中的行为符合缓存规则预期。
3. 校验回源 Host 与 URL 鉴权配置：源站日志中应出现正确的 Host 与鉴权参数。
4. 验证 HTTPS 证书链完整、协议版本符合安全基线要求。
5. 灰度切量：先将部分流量切换至 CDN，观察错误率、回源带宽与源站负载，指标平稳后再全量切换。
6. 验证通过后在工单中回填验证结论、生效时间与观测数据，由运维归档。

## 配置参数

CDN 加速域名的配置项在星澜云控制台中按域名维度维护。每次修改都需提交并下发，配置下发完成前不影响已有流量。下表列出常用关键参数及其默认值、取值范围。

**关键参数表**

| 参数 | 说明 | 默认值 | 取值范围 |
| --- | --- | --- | --- |
| 缓存开关 | 是否对命中缓存规则的请求启用边缘缓存 | 开启 | 开启 / 关闭 |
| 缓存过期时间 | 边缘节点缓存内容的有效期 | 遵循源站 Cache-Control 响应头 | 遵循源站 / 按路径自定义覆盖 |
| 回源协议 | 节点回源时使用的协议 | 跟随客户端请求 | 跟随客户端 / HTTP / HTTPS |
| 回源 Host | 回源请求携带的 Host 头 | 加速域名本身 | 加速域名 / 自定义源站域名 |
| 文件压缩 | 对文本类响应启用压缩 | 关闭 | 开启 / 关闭 |
| 访问日志投递 | 是否将访问日志投递至日志服务 | 开启 | 开启 / 关闭 |
| 日志保留 | 访问日志的保存周期 | 日志在线保留 30 天，归档保留 365 天 | 在线、归档两档，按上述周期执行 |

**默认值**

新建加速域名时，系统按上表默认值初始化配置，无需逐项修改即可完成接入。缓存开关、访问日志投递默认开启；文件压缩默认关闭，开启前需确认源站未对同一资源重复压缩。回源协议与回源 Host 的默认值适用于源站与加速域名同源的常规场景，源站为独立域名时需显式调整回源 Host。日志保留为平台统一策略，默认即为日志在线保留 30 天，归档保留 365 天。

**取值范围**

开关型参数仅支持“开启”和“关闭”两个取值，不接受空值。枚举型参数需在星澜云控制台的下拉列表中选择，手工填写无效值将导致提交校验失败。缓存过期时间为非数值型配置：选择“遵循源站”时由源站响应头决定实际有效期；选择“按路径自定义覆盖”时，须在规则中为每条路径指定策略，未命中任何规则的请求回落至源站策略。修改日志保留相关配置前，请确认归档数据已完成转存，避免出现日志缺口。所有变更在星澜云控制台的配置变更记录中留痕，可回溯提交人与提交时间。

## FAQ

**Q1：在星澜云控制台修改 CDN 加速域名配置后，为什么在星澜工作台里检索不到最新结果？**

CDN 加速域名配置的变更由星澜云控制台受理，星澜工作台通过搜索服务对配置快照建立索引。索引刷新存在延迟，搜索服务索引刷新延迟不超过 5 秒，因此提交变更后请等待刷新完成再检索。若超过该延迟仍检索不到，请先在星澜云控制台确认变更已提交成功并查看该域名的配置版本记录，再提交工单，说明加速域名、操作时间与操作人。

**Q2：CDN 访问日志可以查询多久？超出在线保留期后如何获取？**

日志在线保留 30 天，归档保留 365 天。在线保留期内，可在星澜云控制台按加速域名与时间范围直接检索、下载；需要更早的日志时，请走归档申请流程，说明加速域名、时间范围与用途，由平台侧从归档中恢复后交付。日志仅用于排障与审计，请勿导出到非受控环境或长期留存于个人终端。

**Q3：CDN 配置变更出现异常时如何回滚？**

变更前请先在测试域名验证，确认无误后再应用到正式加速域名。正式环境出现异常时，优先在星澜云控制台使用该域名的配置版本记录回滚到上一个已验证版本，并在工单中登记回滚原因与影响范围；回滚后需重新核对缓存策略与回源设置，确认业务恢复正常后再关闭工单。

## 配额与限制

配额与限制分为频率限制、容量上限与超限行为三类，统一在星澜云控制台的「配额中心」中查看与申请调整，星澜工作台的 CDN 管理页同步展示当前用量与剩余额度。

**频率限制**

- 配置类接口（新增或修改加速域名、缓存规则、回源配置、证书绑定）按账号与接口维度限流，控制台手动操作与 API 调用共用同一份额度。
- 刷新与预热任务按提交次数和 URL 条数限流，批量提交时请拆分批次并留出间隔，避免与其他发布任务叠加。
- 查询类接口（用量查询、日志下载地址获取）单独限流，不占用配置类接口额度。
- 具体阈值以「配额中心」页面当前展示值为准；需要提高阈值时提交工单说明业务场景与预期峰值，审批通过后生效。

**容量上限**

- 单账号可纳管的加速域名数量、单域名可配置的缓存规则条数与回源规则条数均设有上限。
- 单次刷新或预热任务提交的 URL 条数、单日累计条数均设有上限。
- 日志存储：CDN 访问日志在线保留 30 天，归档保留 365 天；超出在线保留期的日志只能通过归档取回。
- 证书数量、自定义请求头数量等附属资源同样计入配额，清理不再使用的资源可释放额度。

**超限行为**

- 触发频率限制时，接口返回限流错误码，控制台提示操作过于频繁；请采用退避重试，不要短时间密集重试。
- 超出容量上限时，新建或保存操作被拒绝并指明具体配额项，已生效配置与线上流量不受影响。
- 刷新或预热任务超出额度时不予受理，需等待额度恢复或完成提额后重新提交。
- 日志超过在线保留期后不再支持在线检索，需从归档恢复；排障取证请提前规划时间窗口。
- 配额变更与超限拦截记录均写入审计日志，可在星澜工作台搜索中查询，搜索服务索引刷新延迟不超过 5 秒。
