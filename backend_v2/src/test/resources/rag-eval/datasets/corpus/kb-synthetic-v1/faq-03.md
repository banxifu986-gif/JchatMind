# 打印机与扫描 FAQ

本文档为企业内部知识库文档，供员工与系统检索使用。

## 问题描述

**用户原始问法**

本节汇总星澜工作台 IT 服务台中反复出现的打印机与扫描类咨询。用户通常不会直接说“打印机故障”，而是用下面这类原话提问：

- “我在星澜工作台点了打印，打印机面板一直显示正在接收，等了十几分钟还没出纸，需要重新提交一次吗？”
- “扫描的时候机器提示发送成功，但我的邮箱一直没收到附件，到底发出去没有？”
- “换了工位之后，原来那台打印机在电脑的打印机列表里找不到了，需要重新申请权限吗？”
- “共享打印机提示需要认证，我用账号登录后显示无权限，这个权限应该找谁批？”
- “打印出来的文件缺页、字迹发灰，是打印机坏了还是文件本身的问题？”

**发生场景**

- 设备与位置：总部北京办公区、上海研发中心各楼层配置的部门共享打印机与一体机，支持打印、复印、扫描，通过办公网接入，员工用办公笔记本或星澜工作台的云桌面发起任务。
- 高发时机：新员工入职首周配置办公设备；工位调整或部门搬迁后重新绑定打印机；月末、季末报表集中打印；合同、发票等需要扫描回传的流程节点。
- 权限场景：共享打印机按部门划分使用范围，首次使用或跨部门借用时，需在星澜工作台提交账号权限申请，审批人为直属主管与系统 Owner 双审批；未完成审批前，设备端会持续提示无权限。
- 故障场景：打印队列卡单、耗材或纸张耗尽、扫描件未送达指定邮箱、驱动版本与操作系统不匹配等。
- 边界说明：打印与扫描属于办公辅助服务，不属于核心服务可用性 SLA 为 99.95% 的覆盖范围，相关报障按 IT 服务台常规工单流程受理。

## 注意事项

本节汇总在星澜科技使用打印机与扫描服务时最容易忽略的三类约束：权限要求、时效限制与易错点。请在提交申请或发起扫描任务前逐项核对，避免因信息缺失导致流程被退回或任务失败。

**一、权限要求**

1. 打印与扫描相关的账号权限不随入职自动开通，需由本人通过星澜工作台提交权限申请。
2. 权限申请的审批路径为：**账号权限申请审批人为直属主管与系统 Owner 双审批**。两位审批人缺一不可，任一环节未通过，申请即处于未生效状态，此时无法在星澜云控制台或办公区复合机上完成认证打印、扫描到邮箱等操作。
3. 请勿借用同事账号或工牌代为打印、扫描。涉及客户资料、合同与内部经营数据的文件，必须使用本人账号操作，以便审计追溯。
4. 若需为外包人员、实习生或临时项目成员开通权限，应由其对接的正式员工发起申请，并在申请单中写明使用期限与用途，同样需经直属主管与系统 Owner 双审批。

**二、时效限制**

1. 权限申请提交后请预留审批时间，不要在临近提交材料或会议前才发起申请。审批通过后权限按申请单填写的有效期生效，到期自动回收。
2. 打印任务在复合机上的保留时间有限，超时未取件将被系统自动清除，需重新发起打印。请在打印后尽快到设备旁完成刷卡取件，不要长时间滞留敏感文件。
3. 扫描到邮箱、扫描到共享目录的任务同样存在时效窗口，若长时间未收到扫描件，应先确认任务是否已超时失效，再排查邮箱容量与网络。
4. 权限到期续期、设备故障报修均需重新走流程，请勿默认「上次能用这次也能用」。核心服务可用性 SLA 为 99.95%，但办公区打印机为终端设备，不在该指标覆盖范围内，出现故障请以报修单受理时间为准。

**三、易错点**

1. **只等一位审批人**：误以为直属主管同意即可使用，实际需双审批全部完成。
2. **申请单用途填写笼统**：仅写「工作需要」易被退回，应写明具体打印或扫描的资料类型。
3. **未核对默认打印机**：切换办公区或连接远程桌面后，默认打印机可能仍指向上一地点设备，导致文件输出到异地。
4. **扫描件发送至个人外部邮箱**：涉及内部资料时，应发送至公司邮箱或指定共享目录。
5. **取件后未清点**：多页文件容易夹带或遗漏，离开设备前请核对页数。
6. **权限变更未同步**：岗位调整或项目结束后，请主动检查权限是否仍与当前职责匹配，避免超范围留存。

如遇上述情形之外的问题，请在星澜工作台提交工单，并附上设备编号、时间点与任务编号，以便快速定位。

## 无法解决时

若按前述步骤仍无法恢复打印或扫描，请按下面的升级路径提交，不要自行拆机或改动网络与驱动配置。

**升级路径**

1. 先向本部门 IT 协调人说明现象、设备编号、所在楼层与已尝试的步骤，由协调人判断是否属于常见故障。
2. 协调人无法处理时，在星澜工作台提交 IT 服务工单，类别选择“办公设备—打印/扫描”，并附上设备编号、故障截图或错误提示原文、发生时间。
3. 涉及星澜云控制台相关打印输出或账号权限问题时，请在工单中注明所用系统与账号，需要开通或调整权限的，按账号权限申请流程办理，审批人为直属主管与系统 Owner 双审批，审批通过后再由 IT 处理。
4. 工单在一线未解决时，由 IT 服务台升级至办公设备二线工程师；涉及办公网、打印服务器或云控制台侧的问题，由二线转交对应运维团队处理，并在工单中同步处理进展。
5. 影响多人或整层办公的问题，请立即电话联系 IT 服务台并按紧急工单处理，同时在工单中标注影响范围。

**响应时效承诺**

IT 服务台在收到工单后按工单优先级响应：一般打印与扫描问题在 1 个工作日内首次响应；影响多人使用的紧急问题在 2 小时内首次响应。首次响应包括确认问题、给出初步判断或说明下一步安排。需要现场处理的，工程师会与您约定上门时间。

上述响应时效针对办公设备支持流程；星澜云控制台所依赖的核心服务可用性 SLA 为 99.95%，该指标用于云服务可用性衡量，不作为单个打印或扫描工单的处理时限。

问题处理完成后，工单会记录处理结论；如对结果有异议，可在工单中回复要求复核，由 IT 服务台负责人跟进。为避免遗漏，请勿在多个渠道重复提交同一问题，补充信息请直接回复原工单。

## 解决步骤

以下步骤适用于通过星澜工作台提交的打印机与扫描类故障。请按顺序执行，每步完成后先确认预期结果；如果未达到预期结果，再查看该步的失败检查点，不要跳过步骤。

1. **确认设备在线状态。** 在星澜工作台「IT 服务」中查看目标打印机状态。预期结果：设备显示“在线”，且没有耗材或卡纸告警。失败检查点：如果显示“离线”或“维护中”，请记录设备编号与所在楼层（北京总部或上海研发中心），然后直接转至第 6 步。

2. **检查终端连接与打印队列。** 确认终端已接入公司有线网络或 Wi-Fi，并清空卡死的打印任务。预期结果：打印队列为空，驱动版本与工作台公示版本一致。失败检查点：如果存在长时间处于“正在打印”的任务，清除后重试；如果驱动版本不一致，请按工作台指引重装后再继续。

3. **执行测试打印或测试扫描。** 预期结果：测试页在 60 秒内输出，或扫描件成功出现在指定邮箱、共享目录中。失败检查点：如果超时仍无输出，请记录任务提交时间与界面提示的错误码，作为后续工单的附件。

4. **核对扫描目标权限。** 扫描至共享目录或代发邮箱前，须在工作台提交账号权限申请，账号权限申请审批人为直属主管与系统 Owner 双审批。预期结果：申请状态显示“已通过”，目标目录可正常写入。失败检查点：如果状态仍为“待审批”，请联系对应审批人跟进，不要重复提交相同申请。

5. **更换终端或网络复测。** 预期结果：在另一台已授权终端上完成同样操作并成功，可判定为原终端本地问题。失败检查点：如果多台终端同时失败，应按服务端问题处理，转入第 6 步，不要逐台排查。

6. **提交工单并附证据。** 在工作台提交工单，附设备编号、错误码、任务提交时间与复测结果。预期结果：工单生成受理编号并进入 IT 受理队列。失败检查点：核心服务可用性 SLA 为 99.95%；如果属于服务整体不可用，工单将按该指标记录影响时长并同步处理进展。
