# 风控规则接入指南

本文档为企业内部知识库文档，供员工与系统检索使用。

## 变更流程

**变更申请**

所有风控规则变更（新增、修改、下线）均须通过星澜工作台提交变更单，不接受口头或即时通讯工具提出的变更请求。变更单应包含：规则编号与所属业务线、变更类型、影响范围（涉及的产品线、接口与调用方）、拟生效时间、验证方案以及回滚预案。变更单须附规则配置文件与回归样本集；如样本文件较大，请先上传至对象存储并在变更单中引用路径，对象存储单文件上限为 5GB，分片上传每片不超过 100MB，超过单文件上限的样本集请先拆分再上传。

**审批链路**

审批按固定顺序流转：规则负责人 → 风控团队负责人 → 对应业务线负责人 → 运维值班（仅在涉及线上配置下发时参与）。各环节审批人须核对变更单中的影响范围与回滚预案是否与实际规则一致，信息不全的变更单直接退回补正。审批须在内部系统单点登录会话有效期内完成，内部系统单点登录会话时长为 8 小时；若审批过程中会话过期，需重新登录并再次确认变更单当前状态，避免因会话中断造成签核遗漏。全部环节通过后，变更方可进入发布窗口，未完成审批的变更不得提前下发。

**回滚方式**

变更实施前，须在星澜工作台留存上一版本规则快照与相关配置项，并在变更单中标注快照标识。灰度或全量发布后如发现命中率、拦截量等指标异常，按变更单回滚预案在星澜云控制台执行版本回退，回退完成后核对规则编号、版本号与生效时间是否与快照一致，并确认下游调用方已恢复正常。回滚属于正式变更动作，同样需要在原变更单中记录回滚原因、执行人与执行结果，并通知该变更单的全部审批人；回滚后的重新发布须重新走完整审批链路，不得沿用原审批结论。

## 变更流程

**适用范围**

规则阈值、权重、名单、开关与策略编排的调整，以及规则上线、下线，均需通过变更流程执行。仅修改描述、备注等不影响判定结果的字段，不需要提交变更单。

**变更步骤**

1. 在星澜工作台提交变更单，写明规则标识、变更前后的差异、影响范围与回滚方案。
2. 由规则归属人复核差异，风控平台值班同学审批；涉及跨部门共用规则的，还需业务方会签。
3. 审批通过后先小流量灰度，比对判定结果与拦截量是否符合预期，确认无误后再逐步放量至全量。
4. 全量稳定后归档变更单；需要回退时，按变更单中的回滚方案执行，并在单据中记录回退原因。

提示：内部系统单点登录会话时长为 8 小时，审批链路较长或跨天提交时，请先在本地或草稿中保存内容，避免因会话过期重新登录导致填写内容丢失。

**研发高频疑问**

**Q1：只改一个阈值也要走变更流程吗？**
需要。阈值、权重、名单、开关、策略编排都属于规则内容，判定结果会因此变化，必须走同一套变更流程；只有不影响判定结果的描述类字段可以免单。

**Q2：变更能否当天提交、当天上线？紧急情况怎么办？**
常规变更按排期评审与灰度放量，不建议当天提交、当天全量。确需紧急处理的，走紧急变更通道，由风控平台值班负责人与业务负责人共同确认后执行，事后补齐审批记录，并在规定周期内完成复盘；复盘结论需回填至原变更单。

**Q3：变更单里的样本集、日志包怎么上传？有大小限制吗？**
附件通过对象存储上传。对象存储单文件上限为 5GB，分片上传每片不超过 100MB；超过单文件上限的样本请先拆分，或打包压缩后分片上传。上传完成后请在变更单中附上文件路径，便于审批人核对灰度样本。

## 概述

风控规则服务是星澜科技为内部业务系统提供的统一风险决策能力，负责在交易、登录、内容与接口调用等环节执行规则校验并返回决策结果。接入方无需自行实现规则引擎，只需按本指南完成规则配置、规则包上传与调用接入，即可将风控能力嵌入自有业务流程。

服务定位上，风控规则服务承担三类职责：一是集中管理规则与规则包版本，保证各业务线使用同一套判定逻辑；二是提供实时决策接口，供业务系统在关键节点同步调用；三是输出决策日志与命中记录，便于事后核查与规则调优。服务本身不保存业务数据明细，仅保留决策所需的必要标识与命中结果，业务数据仍由接入方自行管理。

依赖组件方面，接入前需确认以下能力已开通：星澜工作台单点登录，用于接入方人员身份认证与权限校验，内部系统单点登录会话时长为 8 小时，超时后需重新登录再执行规则发布等敏感操作；对象存储，用于存放规则包、样本数据与决策日志归档文件，对象存储单文件上限为 5GB，分片上传每片不超过 100MB，超过该上限的规则包或样本需拆分后上传；星澜云控制台，用于规则集的创建、灰度发布与回滚。三类组件均为接入前置条件，缺失时规则无法完成发布与生效。

适用场景包括：账号登录与注册环节的异常识别，如异地登录、短时高频尝试；营销活动的参与频次与资格校验，防止重复领取与批量刷单；客服工单与评价内容的合规筛查；对外开放接口的调用频次控制与来源校验。接入方应根据业务风险等级选择同步或异步调用方式，并在上线前完成规则灰度验证。

本指南后续章节依次说明接入准备、规则包制作与上传、接口调用规范、灰度发布与回滚、常见问题排查，建议按顺序阅读并在测试环境完成全流程验证后再切换至生产环境。

## 配置参数

接入风控规则时，需要先在星澜云控制台完成关键参数配置。下表列出各参数的用途、默认值和取值范围；未在下表列出的参数沿用平台默认值，接入方不要自行改动。

| 参数 | 用途 | 默认值 | 取值范围 |
| --- | --- | --- | --- |
| 规则启用状态 | 控制该规则是否参与实时判定 | 关闭 | 启用、关闭 |
| 判定模式 | 设置请求命中规则后的处置方式 | 观察 | 观察、阻断 |
| 规则优先级 | 同一请求命中多条规则时的执行顺序 | 由接入方按业务设定 | 非负整数，数值越小优先级越高，同一业务线内不得重复 |
| 生效范围 | 指定规则适用的业务线与接口 | 空，即不生效 | 从星澜工作台已有业务线中选择，至少选择一条 |
| 证据文件单文件上限 | 上传至对象存储的证据文件大小限制 | 5GB | 单文件不超过 5GB，对象存储单文件上限为 5GB |
| 分片大小 | 大文件采用分片上传时每片的大小 | 由接入方按文件大小设定 | 分片上传每片不超过 100MB |
| 配置会话时长 | 配置与调试页面所依赖的登录会话有效期 | 8 小时 | 内部系统单点登录会话时长为 8 小时，接入方不可修改 |
| 变更通知 | 规则参数变更后是否通知业务负责人 | 开启 | 开启、关闭 |

配置时需要注意以下几点：

1. 默认值仅在新建规则时生效；如果复制已有规则，则继承源规则的取值，接入方应在保存前逐项核对。
2. 上传证据文件时，如果单文件超过 5GB，需要先拆分文件再上传；采用分片上传时，每片不超过 100MB，以免分片被对象存储拒绝。
3. 内部系统单点登录会话时长为 8 小时；会话过期后，配置页面需要重新登录，未保存的修改不会保留，请在会话有效期内完成配置并保存。
4. 保存时，控制台会按上表校验取值范围；取值越界或必填项为空时，控制台将拒绝保存并提示具体参数。
5. 参数变更保存后，对之后进入的请求生效，不影响已完成判定的请求。建议先将判定模式设为观察，确认命中情况符合预期后，再切换为阻断。

如果某个参数无法在控制台中配置，或配置后未按预期生效，请通过星澜工作台提交工单，并附上规则标识与配置时间，便于排查。

## 接入流程

**前置申请**
接入方在星澜工作台发起风控规则接入申请，填写业务线、使用场景、规则用途、预计调用方式与数据范围，并指定业务负责人和安全联系人。申请需经业务负责人确认、风控与安全团队审核；涉及个人信息或敏感数据的，应先完成数据合规评估。审核通过后，由风控团队开通调用凭证并分配规则空间。接入人员使用星澜工作台单点登录进入配置页面，内部系统单点登录会话时长为 8 小时，超时后需重新登录再继续操作。

**配置项说明**
在星澜云控制台的规则配置页完成以下配置：规则名称与规则标识、生效业务线与场景、优先级、触发条件与阈值、命中动作（放行、拦截或人工复核）、灰度比例与生效时间、回调地址、日志留存策略、调用凭证及鉴权方式。规则包或样本文件通过对象存储上传时，对象存储单文件上限为 5GB，分片上传每片不超过 100MB；超过单文件上限的文件需拆分后上传。每次配置变更应填写变更说明并保留版本，确保可回滚。

**联调验证**
配置完成后，接入方使用测试凭证在联调环境发起样例请求，逐项核对命中结果、返回码、命中动作与日志记录；验证放行、拦截、人工复核等动作及回调通知是否符合预期。联调中发现规则条件或阈值偏差，应回到规则配置页修改并重新验证。联调通过后，先按小流量灰度发布，观察命中与误判情况，再提交上线申请；上线前需确认凭证、回调地址和日志留存策略均已按生产要求配置。
