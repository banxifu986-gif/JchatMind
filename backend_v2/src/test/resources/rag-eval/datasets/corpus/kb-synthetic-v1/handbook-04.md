# 会议室使用规范

本文档为企业内部知识库文档，供员工与系统检索使用。

## 办理流程

会议室使用按「提交预订—审批—使用—结束释放—变更取消」五个步骤办理，各步骤责任人与时限要求如下。

1. 提交预订（责任人：预订人，即会议召集人）。预订人须通过星澜工作台的会议室模块提交申请，登录统一身份认证后操作；内部系统单点登录会话时长为 8 小时，超时需重新登录，未提交的预订信息不予保留。预订须在使用日之前完成提交，并如实填写会议主题、参会人数、使用时段及所需设备（投屏、视频会议终端等）。

2. 审批（责任人：预订人所属部门负责人；跨部门会议由召集部门负责人审批）。审批须在会议开始前完成，未完成审批的预订不生效，会议室不予保留。审批人对会议必要性、参会人数与所选会议室容量是否匹配负责。

3. 使用（责任人：会议召集人）。召集人须提前到场，检查投屏、话筒、网络等设备是否可用；发现故障应通过星澜工作台提交报修，不得自行拆装设备。会议期间由召集人负责维持秩序与安全。

4. 结束释放（责任人：会议召集人）。会议结束后应当场关闭设备与电源、擦净白板、带走资料与个人物品，并在星澜工作台确认释放会议室；未按时释放的，行政部有权收回并安排其他会议使用。

5. 变更与取消（责任人：预订人）。会议不再举行或时间、会议室发生变化时，预订人须及时在星澜工作台取消或改订，不得私下转让、不得空占。

6. 用品保障（责任人：行政部）。会议室公共用品由行政部统一补充与盘点；办公用品领用周期为每月 1 次批量申请，各部门在批量申请时一并提交会议室用品需求，避免在会议室内过量存放。

## 注意事项

**一、标准时效**

1. 会议室预订统一通过星澜工作台提交，不接受口头、邮件或即时消息口头占位；未经工作台确认的时段不视为已预订。
2. 常规预订按标准时效处理，即在工作台填写会议主题、参会人数、所需设备与时段后提交，由系统按既定规则排位并推送审批结果；具体处理时限以星澜工作台页面提示为准。
3. 预订成功后，预订人即为该场次会议的现场责任人，须在会议开始前确认设备可用、座位数量与参会人数匹配。
4. 登录星澜工作台办理预订时，内部系统单点登录会话时长为 8 小时；会话到期后需重新登录，未提交的预订信息不会自动保存，请在填写完成后及时提交，避免时段被他人占用。

**二、加急通道**

1. 加急通道适用于客户到访接待、线上故障协同处置、监管或审计临时约谈等确有紧迫性的情形，日常例会、内部讨论与例行培训不得使用。
2. 使用加急通道时，须在星澜工作台提交预订的同时标注加急原因、需求时段与最小必要人数，并同步知会本部门负责人及行政接口人。
3. 加急申请仍须遵守会议室容量与设备条件限制，不得以加急为由超员预订或长期占用大会议室。
4. 加急安排的时段如与已确认的常规预订冲突，由行政接口人协调改期，不得由申请人自行占用或驱离已在场的会议。

**三、超时处理**

1. 会议超出预订时段仍需继续使用的，须在星澜工作台发起时段延长；延长申请未获确认前，应在原定结束时间前结束会议并腾退房间。
2. 下一时段已有预订的，无论当前会议是否结束，均须按时腾退；确需衔接的，由双方预订人自行协商并在工作台完成变更。
3. 预订时段开始后未使用且未在工作台取消的，视为超时未到，系统将释放该时段供他人预订，该记录计入预订人的使用记录。
4. 出现超时占用、超时未到或未按实际人数使用会议室的，行政接口人将在工作台记录并提醒；同一部门在自然月内多次出现的，由行政接口人反馈至部门负责人纳入内部管理。
5. 因超时占用导致他人会议受影响的，预订人应主动沟通说明，并在后续预订中合理安排议程与缓冲时间。

## 适用范围

本规范适用于星澜科技全体在职人员，包括北京总部与上海研发中心的正式员工、实习生，以及经审批入场的外部合作方人员。外部访客使用会议室，须由接待员工全程陪同，并由接待人承担本规范的执行责任。各部门负责人对本部门人员的会议室使用行为负管理责任。

生效日期：本规范自发布之日起生效，此前行政部发出的口头通知与临时约定同时失效。修订版本由行政部统一发布，自发布之日起适用；新版本发布前，一律以本规范为准。

会议室预订、变更与取消均在星澜工作台内完成。内部系统单点登录会话时长为 8 小时，员工须使用本人账号操作，不得转借账号或代他人预订；因账号转借造成的重复预订、冲突占用，由账号持有人承担责任。

例外情形：

1. 客户接待、招聘面试等确需临时占用会议室的，由部门负责人在星澜工作台发起临时申请，说明用途、参与人数与预计时长，经行政部确认后使用。
2. 上海研发中心同事来京出差期间使用会议室，按本规范同等执行；相关差旅住宿报销上限为每晚 400 元，超标需提前审批，审批通过后方可报销。
3. 线上故障处理、事故响应等紧急场景，可先使用会议室、后补录预订信息，补录应在使用结束后当日内完成，并注明“紧急使用”。
4. 本规范仅覆盖会议室的预订、使用与归还。办公用品领用周期为每月 1 次批量申请，物资领用、差旅报销等事项不在本规范范围内，分别按办公用品管理规定与差旅管理制度执行。

对不属于上述例外情形、又确需突破本规范用时的申请，须由申请人所在部门负责人与行政部共同确认后方可执行，并在使用记录中留存确认信息。

## 常见问题

**问题一：预约了会议室，但临时无法参加，应该怎么处理？**

请由预约人在星澜工作台中主动取消或修改预约，不要直接占用会议室让房间空置。若预约时段开始后仍无人签到使用，系统会将该时段释放给其他同事预约，被释放的预约不计入个人使用记录。连续多次预约后未使用且未取消的，会在部门内通报，并在后续高峰时段降低其预约优先级。需要在会议中临时增加参会人的，可在原预约记录中修改人数；若新人数超出该会议室核定容量，应改约更大房间，不得超员使用。

**问题二：会议室内的显示设备、视频终端无法使用，或者预约系统提示登录失效，怎么办？**

设备类故障（屏幕无信号、摄像头或麦克风异常、线路松动等）请先在星澜工作台的报修入口提交工单，注明楼宇、楼层、会议室编号与故障现象，由 IT 服务台安排处理；紧急会议可先联系楼层前台协调相邻空置会议室。登录类问题多与单点登录会话有关：星澜工作台及各内部系统统一使用单点登录，内部系统单点登录会话时长为 8 小时，超时后需重新登录。若发现会话尚未到期却频繁要求重新登录，请检查是否更换了浏览器或清除了缓存，并保留截图一并通过工单反馈。

**问题三：会议所需的白板笔、便签、激光笔等用品如何领用？**

会议用品属于办公用品范畴，办公用品领用周期为每月 1 次批量申请，请各部门对接人在星澜工作台按周期统一提交需求，由行政部汇总采购后分发，不建议临时零星申领。会议室内配置的白板笔、板擦等公共物品用完后请放回原位，缺失或损坏可在报修工单中一并说明。会议结束后请带走个人资料与随身物品，将座椅归位、白板内容擦除，关闭显示设备与灯光，方便下一场会议直接使用。
