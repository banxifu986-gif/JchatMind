# 差旅管理制度

本文档为企业内部知识库文档，供员工与系统检索使用。

## 常见问题

以下为差旅相关的高频疑问与解答，如仍有不明之处，可先查阅本制度正文，再联系直属主管或人力资源部确认。

**问题一：出差期间行程紧张漏打卡，能否补卡？**

可以。请在返回后及时通过星澜工作台提交补卡申请，注明出差事由、出差时间段与对应的审批记录，由直属主管确认。需要说明的是，考勤补卡每月不超过 3 次，请合理规划出差期间的打卡操作，避免占用补卡额度；如当月已超出该次数，需由直属主管说明具体情况后另行处理。

**问题二：处于试用期的员工可以安排出差吗？**

可以。公司试用期时长为 3 个月，最长不超过 6 个月，试用期员工因业务需要出差的，同样适用本制度，出差申请、审批与事后报销流程与正式员工一致，均由直属主管审批。建议直属主管在安排试用期员工出差时，同步明确工作目标与随行人员，便于出差结束后进行工作复盘。

**问题三：出差途中在公司外部网络登录星澜工作台、星澜云控制台，需要注意什么？**

请注意账号安全。账号密码每 90 天强制更换一次，建议在出差前确认密码有效期，避免在异地处理审批或客户事宜时被强制登出、影响行程安排。同时不得在公共设备或他人设备上保存密码，不得将账号转借他人使用；涉及客户数据与内部资料的操作，应在公司认可的访问方式下进行，发现异常登录应立即修改密码并告知信息安全对接人。

## 违规与处理

差旅违规行为按情节轻重分为三级：一般违规、较重违规、严重违规。认定以事实与证据为准，处理结果在星澜工作台内记录并告知本人。

**一般违规** 适用于情节较轻、未造成公司损失的情形，包括：出差申请要素填写不规范被退回；审批完成后行程发生变更，未及时在星澜工作台更新；报销单据附件不齐全但经核实不涉及金额不实；未在规定时限内提交报销单据。处理方式为：由所在部门负责人书面提醒，退回补正后重新提交；同一类问题重复出现的，纳入当期绩效沟通记录。

**较重违规** 适用于违反流程并可能造成费用风险的情形，包括：未提交出差申请即先行出行；超出住宿或交通工具标准且未事前审批；将非差旅费用混入差旅报销；出差结束后长期不办理报销或结算。处理方式为：退回不合规金额，由部门负责人与人力资源部共同约谈并出具书面警示，取消当年度评优资格。

**严重违规** 适用于主观故意、性质恶劣的情形，包括：虚构出差行程；伪造、篡改或重复使用票据；代他人报销或出借个人账号为他人报销；泄露差旅与费用数据。处理方式为：全额追回相关款项，视情节给予警告直至解除劳动合同；涉嫌违法犯罪的，移交司法机关处理。

与流程相关的两类情形一并纳入本制度管理：其一，出差期间因个人原因未在星澜工作台提交出差申请而导致考勤异常的，应按考勤管理规定办理补卡，考勤补卡每月不超过 3 次，超出部分按一般违规处理；其二，星澜工作台与星澜云控制台账号密码每 90 天强制更换一次，因未按期更换导致无法提交差旅申请或报销单据的，不作为免责理由，仍按相应违规等级认定。

**申诉途径**：员工对处理结果有异议的，可自收到处理通知之日起，在通知载明的期限内向人力资源部提交书面申诉，说明理由并附相关证据材料；人力资源部应在收到申诉后会同财务部复核，并将复核结论书面反馈申诉人。申诉期间，原处理决定不停止执行；对复核结论仍有异议的，可向员工关系委员会提出最终申诉，其结论为最终处理结果。申诉材料与处理记录一并归档，保存期限按公司档案管理规定执行。

## 审核时效

标准时效。员工在星澜工作台提交出差申请后，系统按出差类型与费用规模，把审批单分派给直属主管、部门负责人及财务审核人。各环节审核人应在收到审批单当日完成处理；确需核实的，应在审批单中留言说明并给出预计完成时间，不得无故滞留。审批单处于待审核状态的时间计入标准时效；被退回补正的，自重新提交起重新计算。审核人应指定代理人，避免休假或出差期间审批链中断。

加急通道。因客户现场故障、投标截止等紧急事由需即时出差的，提交人可在星澜工作台勾选加急标记，填写事由、出发时间与必要性说明，系统同时推送至全部审核人。加急单优先于普通单处理，审核人不得以非工作时段为由拒绝受理。加急标记仅用于确有紧急事由的行程；滥用加急标记的，相关审批记录纳入差旅合规复核。

超时处理。审批单超过标准时效仍未处理的，星澜工作台自动向审核人及其上级发送催办提醒；经催办仍无进展的，可由提交人所在部门负责人转授权他人代审，代审记录全程留痕。因审核超时导致行程延误或票务损失的，由对应审核环节的责任人说明原因，并纳入部门月度流程复盘。

关联事项。出差期间出现考勤异常的，应按考勤制度办理补卡，考勤补卡每月不超过 3 次；审批系统账号密码每 90 天强制更换一次，密码过期将无法登录星澜工作台处理审批，请提前更换。试用期员工的出差申请由直属主管与人力资源对接人共同确认，试用期时长为 3 个月，最长不超过 6 个月，试用期内的差旅费用标准与正式员工一致。

## 办理流程

办理差旅事项统一通过星澜工作台发起；涉及云产品演示或客户环境访问的，须同时在星澜云控制台完成相应权限申请。整体流程按以下步骤顺序执行，各步骤责任人与时限要求如下。

第一步，出差申请。由出差人本人在星澜工作台提交出差申请，填写出差事由、目的地、起止日期、同行人员及费用预估，并注明是否需要预借差旅费。时限要求：申请须在预订交通与住宿之前提交，未获批准不得先行预订。试用期员工出差的，申请须由直线经理与部门负责人共同确认；试用期时长为 3 个月，最长不超过 6 个月，直线经理应在审批意见中说明试用期内的工作安排与交接方式。

第二步，审批。直线经理为第一责任人，负责核对出差必要性与费用预估合理性；部门负责人为第二责任人，负责审批跨城市、跨部门或费用预估超出常规的申请；涉及星澜云控制台客户环境访问的，还须由信息安全岗复核。时限要求：各审批人应及时处理星澜工作台待办，出差人应在提交后主动跟进审批进度，避免因审批未完成影响既定行程。

第三步，预订与借款。审批通过后，由出差人按公司协议渠道预订交通与住宿；需预借差旅费的，由部门负责人在星澜工作台确认，财务部差旅专员办理付款。时限要求：预订与借款手续须在出发前完成；前一笔借款未结清的，不得再次申请借款。

第四步，行前准备。出差人应检查星澜工作台账号是否可正常使用，账号密码每 90 天强制更换一次，如密码临近有效期，应先完成更换再出行；需携带办公设备的，按资产管理制度登记后带出。

第五步，出差期间考勤。出差人按出差申请所列行程记录出勤；因行程变动确实无法正常打卡的，返程后由本人在星澜工作台提交考勤补卡申请，考勤补卡每月不超过 3 次，并由直线经理确认。

第六步，报销与归档。出差结束后，由出差人整理票据并在星澜工作台提交差旅报销单，部门负责人审核业务真实性，财务部差旅专员复核票据合规性并办理结算。时限要求：报销单须在财务部公布的当期报销时限内提交，逾期提交的须附情况说明并经部门负责人签字确认。行程结束后，出差人应在星澜工作台关闭出差申请单，形成完整闭环记录。

## 适用范围

本制度适用于星澜科技全体在职员工，包括北京总部与上海研发中心的正式员工、试用期员工及经批准的全职实习人员。试用期时长为 3 个月，最长不超过 6 个月，试用期内员工因公出差同样适用本制度，差旅申请与报销流程与正式员工一致；涉及费用标准的部分，按员工本人职级对应的标准执行，不得借用他人职级。劳务派遣人员、外部顾问及供应商人员不适用本制度，其差旅安排由对接部门在合作合同中另行约定，并由对接部门负责人审核。

生效日期：本制度自正式发布之日起生效，发布日期以星澜工作台公告栏发布的版本为准；后续修订版本同样自公告发布之日起生效，旧版本同时废止。员工在制度生效之日前已完成审批的出差行程，按原规定报销；生效之日及之后提交的出差申请，一律按本制度执行。

例外情形：

1. 紧急出差。因客户现场故障、重大投标等紧急事项无法提前完成线上审批的，可先由直属主管口头同意出行，并在返程后 2 个工作日内于星澜工作台补交申请，逾期未补交的视为未审批出差。

2. 考勤处理。出差期间因行程原因未能正常打卡的，应按考勤规定提交补卡申请，考勤补卡每月不超过 3 次，超出部分需由部门负责人说明原因后报人力资源部处理。

3. 系统与账号。出差期间通过外部网络访问星澜工作台与星澜云控制台的，须遵守信息安全要求，账号密码每 90 天强制更换一次，不得以出差为由申请延期，也不得在公共设备上保存登录凭证。

4. 特殊费用。因目的地突发情况、航班取消等不可控因素导致费用超出标准的，员工应在报销单中附情况说明与凭证，由部门负责人与财务部逐级审批后据实报销。

5. 制度冲突。本制度与国家法律法规、公司其他已发布制度存在冲突的，以法律法规及公司正式发布的制度为准，并由人力资源部负责解释与修订。

## 申请条件

**一、前置条件**

1. 出差事由须与本人岗位职责或已立项的项目直接相关，并能说明出差拟达成的具体目标（如客户现场支持、项目实施、供应商洽谈等）。
2. 出差行程须已明确目的地、起止日期、随行人员及承担费用的成本中心，不接受“待定”行程提交申请。
3. 出差申请须通过星澜工作台提交。员工登录星澜工作台的账号密码每 90 天强制更换一次，密码过期将无法提交申请；如遇此情况，请先在星澜工作台完成密码更换，再发起出差流程。
4. 处于试用期的员工可以申请出差。公司试用期时长为 3 个月，最长不超过 6 个月；试用期员工出差须由直属主管与部门负责人共同确认后方可提交。
5. 出差期间的考勤以已批准的出差单为准，无需另行补卡；确因遗漏需要补卡的，按公司考勤制度执行，考勤补卡每月不超过 3 次。

**二、所需材料**

1. 出差申请单：在星澜工作台填写出差事由、目的地、起止时间、预计费用总额及成本中心。
2. 出差事由证明材料：客户拜访函、会议邀请、项目立项或实施说明、培训通知等任一项即可。
3. 行程与费用预算明细：交通方式、住宿天数及各项预计支出，需与成本中心一致。
4. 涉及跨部门协作的出差，需附协作部门负责人的确认意见。
5. 涉及外部单位接待或参与的，需附对方出具的活动安排或邀请材料。

**三、审批权限**

1. 部门内常规出差：由直属主管审批。
2. 北京总部与上海研发中心之间的跨区域出差，或涉及两个及以上部门的出差：由直属主管审批后，报部门负责人审批。
3. 试用期员工出差：由直属主管与部门负责人共同审批，二者缺一不可。
4. 行程超出已批准预算或需临时变更成本中心的：在原审批链基础上追加财务审核。
5. 审批须在出差开始前完成；未经批准自行出行的，相关费用不予报销。审批通过后，申请单同步归档至星澜工作台，作为考勤与报销的依据。
