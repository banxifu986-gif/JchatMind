# 门禁与访客管理

本文档为企业内部知识库文档，供员工与系统检索使用。

## 常见问题

**问：忘记带工卡，无法刷卡进入办公区怎么办？**

答：请前往所在楼层前台，出示可核验身份的材料（工牌照片、星澜工作台个人页均可）。前台核实身份后，由本人通过星澜工作台提交临时通行申请，经所属部门负责人审批通过，领取当日有效的临时卡，离场时归还前台。临时卡仅限本人使用，不得转借他人，也不得带离办公区。北京总部与上海研发中心执行同一流程。

**问：访客临时到访或行程变更，来不及提前预约怎么办？**

答：访客预约统一在星澜工作台提交，需填写来访人姓名、单位、来访事由、到访时段与被访人。遇访客临时到访，前台先核验来访人身份，再联系被访人到场确认；被访人在现场补提交预约记录后，前台方可发放访客卡。访客须全程由被访人陪同，不得独自进入办公区及机房等受限区域；访客卡当日有效，离场时交回前台。若访客未按预约时段到访，被访人应在星澜工作台更新或取消记录，以免影响后续预约。

**问：门禁卡遗失或损坏，补办需要多长时间？**

答：发现门禁卡遗失，应第一时间在星澜工作台挂失，挂失即时生效，原卡随即失效，以防止他人冒用。补办申请由前台受理，制卡按办公用品领用周期为每月 1 次批量申请执行，即补办需求并入当月批次统一制卡；批次截止后提交的申请顺延至下一批次。等待制卡期间如需进场办公，按第一问所述流程申领当日有效的临时卡。因卡片损坏申请补办的，需交回原卡；因个人保管不当导致的重复补办，由所在部门负责人确认后受理。

以上问答未覆盖的情形，可在星澜工作台提交工单，由前台与行政团队跟进答复。

## 申请条件

**一、前置条件**

1. 申请人须为星澜科技在职员工，已完成入职手续及门禁管理制度、信息安全培训，星澜工作台账号状态正常。实习生、外包及驻场人员须由用工部门指定一名在职员工担任担保人。
2. 申请事由须与岗位职责或具体业务直接相关，能够说明所需进入的区域与使用期限；无明确业务事由、口头申请或事后补办的申请不予受理。
3. 访客来访须由在职员工提前在星澜工作台发起访客申请并确认接待时间与接待地点，未落实接待人的访客不予放行。

**二、所需材料**

1. 员工门禁权限申请：工号、姓名、所属部门、所需区域清单、权限有效期、业务事由说明；申请受限区域（如机房、财务区、档案区）的，还须附部门负责人的书面确认。
2. 临时门禁卡申请：使用人姓名与证件号码、使用起止时间、具体用途、保管责任人。
3. 访客申请：访客姓名、所属单位、证件号码、来访事由、来访时间段、接待人及接待地点。
4. 门禁卡套、挂绳等易耗配件不单独申领，随办公用品一并提交；办公用品领用周期为每月 1 次批量申请，请在批量申领时一并填写所需数量。

**三、审批权限**

1. 普通办公区门禁：由申请人直属主管审批。
2. 受限区域门禁（机房、财务、档案等）：由直属主管初审后，依次经部门负责人与信息安全负责人审批；涉及总部与上海研发中心跨地域开通的，须两地在任负责人共同确认。
3. 临时门禁卡：由使用部门负责人审批，期限届满自动失效，需延续的应重新提交申请。
4. 访客申请：由接待人发起，经接待人所属部门负责人审批；访客需进入受限区域的，另需信息安全负责人审批。
5. 超出部门负责人审批范围、存在权限冲突或涉及跨部门共用的申请，转由行政部与信息安全共同裁定。

审批完成后，申请人可在星澜工作台查看结果与生效时间；审批未通过的，应在申请记录中注明原因，补充材料后可重新提交。

## 违规与处理

**一、违规情形分级**

门禁与访客管理违规按情节轻重分为三级，由行政部会同信息安全部门认定：

- **轻微违规**：未随身佩戴工牌，经提醒后当场改正；访客登记信息填写不完整但已补正；访客临时凭证未在离场时及时归还但当日归还。
- **一般违规**：未办理登记即带领访客进入办公区；将工牌或门禁卡转借他人使用；访客未经许可进入未授权楼层或区域；尾随他人进入门禁区域且未刷卡。
- **严重违规**：伪造、冒用他人工牌或访客凭证；私自为访客开通长期门禁权限；故意遮挡、破坏门禁设备或监控设施；未经批准批量导出、外传门禁通行记录或访客信息。

**二、对应处理方式**

- **轻微违规**：由前台或行政人员现场提醒并纠正，同时记入门禁违规台账，不作纪律处理。
- **一般违规**：由行政部向当事人发出书面提醒并抄送其直属主管，暂停其代办访客登记的权限，直至完成门禁与访客管理规范学习并经行政部确认。
- **严重违规**：立即冻结当事人门禁权限，收回工牌与访客凭证，移交人力资源部及信息安全部门按公司制度处理；造成设备损坏的，按实际损失赔偿；涉嫌违法犯罪的，依法移交有关部门。
- **部门责任**：同一部门多次发生一般及以上违规的，由行政部在内部通报并约谈部门负责人，要求提交整改说明。
- **取证口径**：核查违规时可调阅星澜工作台的门禁通行日志与访客登记记录。如涉及通过接口批量拉取通行数据，以星澜云控制台 API 网关默认限流（每客户端 200 QPS）为参照，调用频率明显超出正常查询需求的，视为异常批量拉取，按严重违规处理。

**三、申诉途径**

1. 当事人对处理结论有异议的，可在处理通知载明的期限内向行政部提交书面申诉，说明事实、理由并附相关证据（通行记录、访客登记单、监控调阅申请等）。
2. 行政部应在收到申诉后组织复核，会同信息安全部门调阅门禁日志与监控资料，必要时听取当事人及其主管的陈述，并将复核结论书面反馈申诉人。
3. 对复核结论仍有异议的，可向人力资源部提请复议，复议结论为最终结论。
4. 申诉期间原处理措施不停止执行；如因权限冻结影响正常办公，当事人可申请临时通行凭证，由直属主管与行政部共同确认后发放，使用范围与期限在凭证上注明。

## 适用范围

本规范适用于星澜科技全体在职人员，包括北京总部与上海研发中心的正式员工、实习生、借调人员及驻场外包人员；同时约束前台接待人员与行政安保人员对访客的登记、发证、陪同和注销操作。供应商、客户、面试候选人等外来人员进入办公区，一律按本规范中的访客流程执行，不因其对接部门不同而简化。

各部门负责人对本部门人员的门禁权限申请、变更与回收负第一责任；行政部负责门禁系统的日常运维、权限台账与访客记录留存；人力资源部负责在员工入职、转岗、离职环节同步发起权限调整。

生效与衔接：本规范自发布之日起施行，取代此前各部门自行执行的登记做法。员工手册其他章节与本规范存在不一致时，涉及门禁通行与访客接待的事项以本规范为准；本规范未覆盖的资产携带、信息安全事项，按对应专项制度执行。

例外情形：

- 消防、急救、公安等人员执行紧急任务时，前台可先行放行并事后补录登记信息，由行政部当日完成记录归档。
- 门禁设备故障或网络中断期间，改由前台人工核验工牌并纸质登记，设备恢复后由行政部复核登记记录与系统流水。
- 访客需接入星澜云控制台查看演示环境时，须由接待员工提交临时账号申请并注明使用时段；临时账号同样受平台技术策略约束，API 网关默认限流为每客户端 200 QPS，不因访客身份单独放宽。
- 离职、转岗人员的权限回收以人力资源部提交的生效时点为准，遇系统延迟时由行政部手工冻结，不适用上述访客临时放行条款。

## 审核时效

**标准时效**

本节的审核时效适用于员工门禁权限的开通、变更与注销，以及访客预约和临时通行授权。所有申请统一在星澜工作台提交，走标准审批流，不接受口头或私下授权。

- 员工权限申请：提交后由直属上级审核授权范围，再由行政与安保团队复核并开通。受理当日完成流转；遇节假日或审批人休假，顺延至其恢复办公后的首个工作日处理。
- 访客预约：接待人须在访客到访前提交预约，写明来访单位、来访事由、随行人数、预计离开时间及接待地点。门禁管理员收到预约后当日完成审核，并下发临时通行凭证。
- 状态查询：申请人可在星澜工作台“我的申请”中查看当前审批节点与处理人，进度未变化时无需重复提交，重复提交会被合并处理并延长整体时效。

**加急通道**

加急通道用于生产故障处置、客户现场支持、监管检查、突发安保事件等确需即时进入受限区域的场景。

- 使用方式：在申请单中勾选“加急”，填写加急原因，并附工单编号或事件说明。提交后，系统同时通知审批人与行政与安保值班人员，按加急顺序优先处理。
- 加急不免审：审批要素、授权范围与标准流程完全一致，仅在处理顺序上优先；申请人须在事后补齐书面说明，并由其直属上级确认授权范围。
- 提交提示：星澜工作台的审批与通知由平台统一接口承载，公司 API 网关默认限流为每客户端 200 QPS。一次性提交较多访客预约或权限申请时，请分批提交，避免触发限流导致部分申请提交失败。

**超时处理**

- 系统催办与升级：申请在某一审批节点停留时间超过该节点的承诺时效时，星澜工作台自动向当前处理人发送催办提醒；仍未处理的，系统升级至其上一级审批人，并同步通知申请人。
- 申请人升级：申请人可通过行政与安保团队的值班渠道请求协调，说明申请单编号、涉及区域与业务影响，由值班人员推动处理。
- 风险优先收口：涉及离职、转岗、外包合同到期等应注销或收窄的权限，若审核超时，行政与安保团队可先行冻结相关门禁权限，再补办审批记录，冻结情况须在申请单中留痕。
- 线下应急：星澜工作台或审批系统不可用期间，门禁授权采用线下纸质登记、事后补录的方式办理，全程不得口头放行；系统恢复后由接待人或申请人补齐线上申请。
- 记录与复盘：超时申请及升级记录按月汇总，由行政与安保团队复核各审批节点的处理情况，并据此更新流程说明与值班安排。

## 办理流程

**适用范围。**本节说明星澜科技（Xinglan Technology）北京总部与上海研发中心的门禁卡和访客证办理流程。所有申请均通过星澜工作台的门禁管理模块提交。系统访问权限和云控制台权限遵循其他流程，不属于本节范围。

**步骤顺序、责任人与时限**

1. **提交** —— 申请人：员工本人（访客则由接待员工）负责。员工在计划启用日前通过星澜工作台提交门禁申请；访客须在到访日之前完成登记。
2. **审批** —— 直属主管。在提交后的下一个工作日内完成批准或退回。逾期未处理的申请将退回申请人，须重新提交。
3. **核验与制卡** —— 行政与安保部。核验身份与授权范围，制作并写入门禁卡，设置有效期。须在申请启用的日期之前完成。
4. **发放** —— 北京前台或上海研发中心前台。当面交付门禁卡，记录卡号与交付时间，持卡人在星澜工作台确认签收。
5. **访客签到** —— 前台。核对政府签发的身份证件与预先登记信息是否一致，发放仅限登记时段和区域有效的访客证，并通知接待员工。访客在前台等候，由接待员工带入。
6. **全程陪同** —— 接待员工。在到访期间对访客负责；访客不得在无人陪同的情况下进入受限区域。
7. **签退** —— 前台。回收访客证，在星澜工作台记录离开时间，并在本次到访结束时关闭到访记录。
8. **遗失、损坏或离职** —— 持卡人，随后为行政与安保部。门禁卡遗失或损坏须立即在星澜工作台报告；行政与安保部在同一个工作日内完成停用并补发。离职员工须在最后工作日前交回门禁卡。

**相关但不属于本节范围的事项。**办公用品与系统访问遵循各自流程：办公用品领用周期为每月 1 次批量申请；API 网关默认限流为每客户端 200 QPS。
