# 企业邮箱配置 FAQ

本文档为企业内部知识库文档，供员工与系统检索使用。

## 无法解决时

如果按前述步骤排查后问题仍然存在，请通过正式渠道升级处理，不要在企业微信群或个人邮件中直接联系运维同事，以免请求遗漏或无人跟进。

**一、升级路径**

1. 一级：在星澜工作台提交服务工单，分类选择「企业邮箱」，并在工单中附上邮箱账号、客户端类型与版本、完整报错截图、问题发生时间以及已尝试过的排查步骤。信息越完整，定位越快。
2. 二级：如果工单在页面展示的时效内没有实质推进，请直接在原工单内回复「申请升级」，由一线支持转交邮箱与账号服务组处理；你也可以拨打星澜工作台首页公示的 IT 服务台电话说明工单编号。
3. 三级：涉及部门或全员收发异常的，请由部门 IT 接口人汇总影响范围后，在工单中标注并提交至邮箱与账号服务组负责人，避免同一问题重复开单。
4. 需要现场核验身份的事项，请携带有效证件前往总部或上海研发中心的 IT 服务台办理；如工牌遗失，工牌补办周期为 3 个工作日，请提前安排时间。

**二、响应时效承诺**

- 工单提交后，星澜工作台会记录受理时间并展示当前处理节点，响应与解决时效以工单页面展示的服务级别约定为准。
- 一线支持会先复现并定位问题；确认需要升级的工单，会在工单内同步升级原因与接手团队，你无需重复提交。
- 处理过程中如需你补充信息，请在原工单内回复；等待补充信息的时间不计入处理时效。
- 问题处理完成后工单关闭；若同一问题再次复现，可在原工单内回复重新打开，无需另开新单。

**三、提交前的两点自查**

- 请勿使用 WiFi 访客网络做收发验证，WiFi 访客网络带宽限制为 10Mbps，大附件与同步测试结果不具备参考性，请在办公有线网络或办公 WiFi 环境下复现。
- 请确认客户端配置与星澜工作台统一推荐的设置一致，并保留完整报错信息，以便支持人员快速比对。

## 解决步骤

以下步骤按顺序执行，每一步都给出预期结果与失败时的检查点。若某一步的预期结果未出现，请先完成该步的检查点再继续，不要跳步操作。

1. **核对邮箱账号状态。** 使用工号登录星澜工作台，进入「账号中心」查看企业邮箱账号状态。预期结果：账号状态显示为「已启用」，且绑定的手机号可正常接收验证码。失败时的检查点：若状态为「未激活」或「已冻结」，先确认是否为新入职未完成开通流程；确需到总部现场办理身份核验而工牌遗失的，工牌补办周期为 3 个工作日，期间可向行政申请临时通行凭证，不必等到新工牌制好后再办理邮箱业务。

2. **核对客户端服务器参数。** 在邮件客户端中手动填写收件与发件服务器地址、端口及加密方式，关闭「自动探测」后重新保存。预期结果：点击「测试连接」后，收件与发件两项均提示连接成功。失败时的检查点：确认未误填个人邮箱域名；确认本地安全软件或公司防火墙未拦截对应端口；确认客户端版本为公司统一分发的版本。

3. **改用客户端授权码认证。** 在星澜工作台「账号中心—安全设置」中生成客户端授权码，以其替代登录密码填入客户端。预期结果：认证通过，客户端开始同步历史邮件。失败时的检查点：检查授权码是否被复制进多余空格；若近期在星澜云控制台修改过登录密码，原授权码会失效，需重新生成后再试。

4. **执行收发验证。** 向本人账号发送一封带附件的测试邮件，并抄送一名同事。预期结果：5 分钟内本人与同事均收到邮件，附件可正常下载打开。失败时的检查点：检查「垃圾邮件」与「已拦截」目录；确认附件未超过单封邮件大小上限；确认收件人地址无拼写错误。

5. **排查网络环境。** 若当前使用的是访客网络，请注意 WiFi 访客网络带宽限制为 10Mbps，大附件同步缓慢或进度停滞多由带宽限制导致。预期结果：切换至办公网络后，邮件同步速度恢复正常、大附件可完整下载。失败时的检查点：确认是否启用了个人热点或代理工具；确认有线与无线未同时连接造成路由冲突。

6. **提交工单并附证据。** 若前五步均未解决问题，在星澜工作台提交 IT 服务工单，附上客户端完整错误提示截图、出错时间点与已尝试的步骤编号。预期结果：工单生成受理编号，并按服务级别约定时间获得响应与处理方案。失败时的检查点：确认工单已选择「企业邮箱」分类，避免因分类错误被转派而延误处理。

## 注意事项

**权限要求**

- 企业邮箱的开通、变更与停用，须由员工本人在星澜工作台提交申请，并经直属主管审批；IT 服务台只按审批结果执行，不接受口头、即时消息或代他人提交的申请。
- 共享邮箱、邮件组、对外统一发件地址的配置，须由部门负责人指定一名责任人，并在申请中注明责任人及其主管；责任人不明的申请将被退回补充。
- 域名解析、网关策略、归档策略等管理员级配置，仅由 IT 基础架构组在星澜云控制台操作，业务部门不得自行修改相关参数。
- 身份核验以工牌为准。工牌遗失需先补办，工牌补办周期为 3 个工作日，此期间无法完成需要现场核验的邮箱业务；入职、转岗人员请提前规划，避免影响邮箱启用时间。

**时效限制**

- 审批通过的申请按提交顺序排队执行，进度以星澜工作台工单状态为准；审批通过后请勿重复提交，重复工单会被合并并重新排序。
- 密码重置、客户端配置类问题在身份核验通过后受理；跨部门、跨主体的权限调整须重新走审批，时效以新的审批完成为准。
- 离职、转岗引起的邮箱停用与交接，以人事流程生效时间为准。员工应在生效前完成个人邮箱与所负责共享邮箱的交接，逾期不再保留个人邮箱内的数据。

**易错点**

- 客户端手动填写服务器地址、端口与加密方式时，容易与标准参数不一致，表现为反复提示密码错误；请优先使用自动配置，确需手动填写时逐项核对。
- 别名与共享邮箱易混淆：别名不是独立邮箱，不能单独设置密码或登录；共享邮箱由责任人统一管理，成员离职后须及时移除其访问权限。
- 在访客网络下进行首次登录与大附件同步容易失败，WiFi 访客网络带宽限制为 10Mbps，请在办公网络内完成配置与验证。
- 转发规则设置后未做验证，可能造成邮件滞留；配置完成后应由本人发送测试邮件确认收件结果。
- 重复创建同名邮件组会产生冲突；更改组名前须先确认没有在用的审批流与自动化规则引用该组地址。

## 问题描述

本小节汇总用户在星澜工作台服务台提交企业邮箱配置类问题时最常见的原始问法，以及这些问题实际发生的场景，供值班同学在受理工单时快速判断问题归属与优先级。

**一、用户原始问法（保留用户原话）**

服务台收到的提问多为口语化描述，常见原话包括：

- “我在星澜云控制台里找不到企业邮箱的配置入口，是不是权限没给我开？”
- “换了新电脑，邮件客户端一直提示密码错误，但网页版能正常登录，到底该怎么配置？”
- “手机端只能收到一部分邮件，服务器地址和端口要填哪个？”
- “入职几天了邮箱还没开通，是不是要等工牌办好才行？”
- “在会议室用访客网络连不上邮箱，是不是网络那边有限制？”

受理时请尽量保留用户原话再转写为规范描述，不要直接用自己的判断替换用户表述，以免丢失关键线索。

**二、发生场景**

1. 新员工入职开通：邮箱开通需要完成身份核验，若工牌尚未领取或遗失后补办，核验环节会顺延。需向用户说明：工牌补办周期为 3 个工作日，邮箱开通时间可能相应晚于入职日期，并非配置错误。
2. 更换终端或重装系统：用户在星澜工作台内更换设备后重新配置客户端，常因沿用旧参数而反复提示认证失败。
3. 移动端首次配置：用户在手机端手动填写服务器地址与端口，参数不完整时表现为只能收部分邮件或长时间同步无结果。
4. 会议与访客网络环境：用户在会议室使用访客接入时，WiFi 访客网络带宽限制为 10Mbps，首次全量同步与大附件收发耗时明显变长，用户容易误判为“邮箱配置失败”。

上述场景均应在问题描述中写明发生时间、所处网络环境、使用终端与已尝试的操作步骤，便于后续环节定位。
