# 办公区 WiFi FAQ

本文档为企业内部知识库文档，供员工与系统检索使用。

## 解决步骤

1. **确认影响范围。** 先询问周边同事是否也同样断网，再分别用手机和笔记本各连接一次办公网。预期结果：能判断是单台设备故障，还是整片办公区断网。失败检查点：如果同楼层多人同时断网，就停止个人排查，直接进入第 6 步报障，并记录首次断网时间和所在楼层工位号。

2. **重新连接办公网。** 在设备的无线网络列表中选择办公网，先执行“忘记此网络”，再重新输入凭据连接。预期结果：设备成功获取地址并显示“已连接”。失败检查点：如果连续提示密码错误，重试不要超过 3 次，以免账号被临时锁定；随后转到第 3 步核对认证状态。

3. **核对账号认证状态。** 打开星澜工作台，确认本人账号可以正常登录且状态可用。预期结果：账号登录正常，说明入网认证凭据有效。失败检查点：如果提示账号异常或需要重新绑定设备，就按工作台提示完成验证；如果身份核验所依赖的门禁工牌已损坏、无法完成核验，需要先补办工牌，工牌补办周期为 3 个工作日，在此期间可请部门负责人在星澜工作台提交临时入网申请。

4. **重启无线网卡与终端。** 关闭无线开关 30 秒后再重新开启，必要时重启设备；同时关闭本机代理、VPN 及第三方网络加速工具。预期结果：无线连接恢复，网页与星澜工作台均可正常打开。失败检查点：如果只有个别应用不通、网页访问正常，说明问题在应用侧而非 WiFi，应转交对应系统负责人。

5. **更换接入位置复测。** 携带设备到同楼层其他区域或会议室重新连接。预期结果：在新位置可以正常上网，说明原位置接入点覆盖或负载异常。失败检查点：如果换位置后仍无法连接，就记录设备型号、操作系统版本和报错截图，进入第 6 步。

6. **提交 IT 报障工单。** 在星澜工作台提交工单，写明工位号、断网起始时间、影响范围和已完成的排查动作。预期结果：收到工单编号与预计响应时间，由 IT 跟进处理。失败检查点：如果工单长时间无人响应，可通过工作台催办；WiFi 中断期间已提交的业务数据不会丢失，数据库备份 RPO 为 15 分钟，RTO 为 2 小时，网络恢复后可继续作业。

## 问题描述

本节汇总员工在星澜工作台提交的办公区 WiFi 相关工单与咨询中最常见的原始问法，以及这些问题的典型发生场景，便于员工先判断自己属于哪一类情况，再对照后续条目处理。

**用户原始问法（保留原话，便于检索）**

- “办公区 WiFi 连上了，但星澜工作台打不开，是不是网络挂了？”
- “换了工位以后 WiFi 一直转圈，重启电脑也没用。”
- “会议室投屏能用，笔记本连 WiFi 却提示认证失败。”
- “新入职、工牌还在补办，没有工牌怎么连办公区 WiFi？”
- “上海研发中心和北京总部是同一个 WiFi 名称吗？出差过去要不要重新申请？”
- “手机能连上，电脑连不上，是什么原因？”
- “WiFi 一天掉线五六次，能不能帮忙查一下？”

**发生场景**

1. 日常工位接入：员工在北京总部或上海研发中心的办公区工位，使用笔记本、台式机或移动设备连接办公区 WiFi，并登录星澜工作台处理智能客服与数据分析相关业务。
2. 会议与协作：在办公区会议室、洽谈区临时接入，涉及投屏、视频会议等用途；此时接入设备多、切换频繁，容易出现认证失败或反复掉线。
3. 人员变动：新员工入职、工牌补办、访客到访等情况下，账号与准入权限尚未同步。工牌补办周期为 3 个工作日，补办期间需先以其他方式完成身份核验，再接入办公区 WiFi。
4. 位置变更：员工在楼层之间、北京总部与上海研发中心之间移动办公，设备保留了旧的接入记录，表现为已连接但无法访问星澜工作台或星澜云控制台。
5. 设备差异：同一账号在手机端正常、在笔记本端异常，需要区分是设备配置、认证证书还是账号权限问题。

以上问法与场景仅用于帮助员工判断问题归属，具体排查与处理步骤见后续条目。

## 注意事项

**一、权限要求**

1. 办公区 WiFi 面向在职员工开放，接入账号与星澜工作台统一身份绑定，必须使用本人账号登录，不得共用账号、代他人认证或将凭证转交外部人员。
2. 访客上网须由接待人在星澜工作台提前提交访客网络申请，注明来访单位、人数与时间段，经审批后于来访当日开通；访客账号仅可访问互联网，不得用于接入任何内部系统。
3. 成功连接办公区 WiFi 仅代表网络接入，不代表获得业务系统权限。访问星澜云控制台等系统仍须按各自的权限流程单独申请，二者不可互相替代。
4. 需要接入研发网段或调试设备的同事，须另行提交网段访问申请，由所在部门负责人与 IT 共同确认后方可开通。

**二、时效限制**

1. 访客网络账号仅在申请填写的来访时段内有效，到期自动失效；如需延长，须由接待人重新提交申请，不得口头告知访客继续使用。
2. 办公区 WiFi 的认证凭证按季度轮换，轮换通知通过星澜工作台发布，请按通知要求及时更新终端配置；逾期未更新的终端将无法完成认证。
3. 员工工牌补办周期为 3 个工作日。补办期间如需临时上网凭证，可出示星澜工作台电子工牌，由前台核验身份后发放，凭证当日有效。
4. 离职、转岗或长期外派人员的上网权限随人事流程同步调整，相关同事应在流程生效前完成设备解绑。

**三、易错点**

1. 常见问题是终端仍连接访客网络却反复尝试访问内部系统，表现为“能上网、打不开系统”。请先在无线列表中切换回办公区 WiFi，再重新登录星澜工作台。
2. 认证失败多由终端保存了旧的凭证或证书引起。请删除该网络的历史配置后重新连接，不要反复输入密码以免触发账号锁定。
3. 办公区 WiFi 中断不影响后端数据安全：数据库备份 RPO 为 15 分钟，RTO 为 2 小时，备份任务在独立链路上按计划执行。断网时请勿自行重启机房设备或改动网络配置，按流程报修即可。
4. 不要在工位私接无线路由器、随身 WiFi 等设备扩展信号，此类设备会引发地址冲突与认证异常，并可能造成网段内的安全风险。
5. 故障报修请在星澜工作台提交工单，写明所在楼层、工位号、终端类型与报错截图，便于 IT 快速定位。

## 无法解决时

**仍无法解决时怎么办**

如果你已经完成前述自查（重新连接 SSID、重启无线网卡、切换 5GHz/2.4GHz、更换工位复测），办公区 WiFi 仍然无法正常接入，请按以下升级路径提交处理，不要自行重启或拔插办公区的无线接入点、交换机等网络设备。

**一、升级路径**

1. 第一级：IT 服务台。在星澜工作台提交 IT 服务工单，分类选择「网络与连接 — 办公区 WiFi」，并在描述中写明：所在办公区（北京总部或上海研发中心）、楼栋与楼层、工位号、连接的 SSID、报错原文或截图、首次发生时间、已尝试的自查步骤。工单是后续所有升级动作的唯一凭据，口头或群内反馈也请补单。
2. 第二级：IT 运维值班。服务台无法远程定位时，会将工单转派至 IT 运维值班人员，由值班人员远程核查认证与地址分配情况；确需现场处理的，会与你约定上门排查时间。
3. 第三级：联合处理。若问题涉及账号、身份认证或权限异常，由 IT 团队与信息安全团队联合排查；若同时涉及工牌挂失或补办，请另行走工牌流程，工牌补办周期为 3 个工作日，工牌流程与网络故障工单互不替代。
4. 第四级：重大事件。当同一楼层、同一楼栋出现多人同时断网，或影响跨楼层、跨办公区办公时，工单将升级为重大事件，由 IT 值班负责人牵头处理，并同步至你所在部门的接口人。
5. 仍未解决时，可通过星澜工作台工单的升级入口逐级升级至 IT 运维负责人、信息技术部负责人，也可致电 IT 服务台说明工单编号申请升级。升级时请保留现场环境与报错截图，便于复现。

**二、响应时效承诺**

工单提交后，系统按你选择的优先级排队，具体的响应时限、进展同步节点与办结标准，以星澜工作台工单页面显示的服务级别为准，请在提交前确认优先级填写是否与实际影响相符；多人受影响的请选择影响面较大的优先级并注明人数。处理过程中，IT 会在工单内记录每次排查结论；升级为重大事件后，会建立专项沟通渠道并按约定节点同步进展。问题恢复后，工单需经你确认方可关闭；若关闭后短时间内复现，请直接回复原工单重新打开，无需另建新单。
