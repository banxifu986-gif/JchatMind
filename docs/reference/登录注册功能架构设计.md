# 登录注册功能架构设计

## 1. 整体架构

```
前端                          后端                           持久层
┌──────────┐    HTTP POST    ┌──────────────┐    MyBatis    ┌────────┐
│ LoginModal│ ──────────────→ │ UserController│ ────────────→ │ MySQL  │
│ Register  │ ←────────────── │      ↓       │ ←──────────── │ (user) │
│ (React)  │   JSON + JWT    │ UserServiceImpl│              └────────┘
└──────────┘                  │      ↓       │
                              │ JwtUtil      │
                              │ PasswordEncoder│
                              │ RequestScopeData│
                              └──────────────┘
```

**核心要点：**
- 注册支持 `账号+密码` 或 `账号+密码+邮箱+验证码` 两种方式
- 登录支持三种方式：`账号+密码`、`邮箱+密码`、`邮箱+验证码`
- 登录成功返回 JWT token，前端每次请求携带 `Authorization: Bearer <token>`
- `whoami` 接口实现滑动过期：每次调用返回新 token，延长有效期

## 2. 后端实现

### 2.1 Controller — `UserController.java`

```
POST /api/users           → register(RegisterRequest)
POST /api/users/login     → login(LoginRequest)
POST /api/users/whoami    → whoami()
```

### 2.2 核心 Service 逻辑 — `UserServiceImpl.java`

```java
// ========== 注册 ==========
@Override
@Transactional(rollbackFor = Exception.class)
public ApiResponse<RegisterVO> register(RegisterRequest request, String ip) {
    // 1. 检查账号唯一性
    if (userMapper.findByAccount(request.getAccount()) != null) {
        throw new BusinessException("账号重复");
    }

    // 2. 如果提供了邮箱，校验验证码
    if (request.getEmail() != null && !request.getEmail().isEmpty()) {
        if (userMapper.findByEmail(request.getEmail()) != null) {
            throw new BusinessException("邮箱已被使用");
        }
        if (!emailService.checkVerificationCode(
                request.getEmail(), request.getVerifyCode(), ip, VerifyCodeType.REGISTER)) {
            throw new BusinessException("验证码无效或已过期");
        }
    }

    // 3. BCrypt 加密密码 + 插入用户
    User user = new User();
    BeanUtils.copyProperties(request, user);
    user.setPassword(passwordEncoder.encode(request.getPassword()));
    userMapper.insert(user);

    // 4. 生成 JWT 并返回
    String token = jwtUtil.generateToken(user.getUserId());
    return ApiResponseUtil.success("注册成功", registerVO, token);
}

// ========== 登录 (支持三种模式) ==========
@Override
public ApiResponse<LoginUserVO> login(LoginRequest request, String ip) {
    User user;

    // 定位用户：验证码模式用邮箱查，密码模式用账号或邮箱查
    if (request.getVerifyCode() != null && !request.getVerifyCode().isBlank()) {
        user = userMapper.findByEmail(request.getEmail());
    } else if (request.getAccount() != null && !request.getAccount().isEmpty()) {
        user = userMapper.findByAccount(request.getAccount());
    } else if (request.getEmail() != null && !request.getEmail().isEmpty()) {
        user = userMapper.findByEmail(request.getEmail());
    } else {
        throw new BusinessException("请提供账号或邮箱");
    }

    // 校验凭证
    if (request.getVerifyCode() != null && !request.getVerifyCode().isBlank()) {
        // 验证码模式
        if (user == null || !emailService.checkVerificationCode(
                request.getEmail(), request.getVerifyCode(), ip, VerifyCodeType.LOGIN)) {
            throw new BusinessException("验证码无效或已过期");
        }
    } else {
        // 密码模式
        if (user == null) throw new BusinessException("用户不存在");
        if (!passwordEncoder.matches(request.getPassword(), user.getPassword())) {
            throw new BusinessException("密码错误");
        }
    }

    // 生成 JWT，更新最后登录时间
    String token = jwtUtil.generateToken(user.getUserId());
    userMapper.updateLastLoginAt(user.getUserId());
    return ApiResponseUtil.success("登录成功", userVO, token);
}

// ========== 自动登录 (滑动过期) ==========
@Override
public ApiResponse<LoginUserVO> whoami() {
    Long userId = requestScopeData.getUserId();
    if (userId == null) throw new BusinessException("用户 ID 异常");

    User user = userMapper.findById(userId);
    if (user == null) throw new BusinessException("用户不存在");

    // 每次调用刷新 token，实现滑动过期
    String newToken = jwtUtil.generateToken(userId);
    userMapper.updateLastLoginAt(userId);
    return ApiResponseUtil.success("自动登录成功", userVO, newToken);
}
```

### 2.3 请求 DTO 设计 — `LoginRequest.java`

```java
// LoginRequest 核心字段 + 自定义校验
// - account: 可选，账号
// - email: 可选，邮箱
// - password: 可选，密码
// - verifyCode: 可选，验证码
//
// 校验规则：account/email 至少填一个，password/verifyCode 至少填一个
// 如果用 verifyCode 登录则 email 必填
```

### 2.4 响应 VO 设计

| VO | 字段 | 说明 |
|---|---|---|
| `TokenApiResponse` | code, message, data, **token** | 带 token 的统一响应 |
| `LoginUserVO` | userId, account, username, avatarUrl, **isAdmin**, email... | 登录后返回的用户信息 |
| `RegisterVO` | userId | 注册成功后返回 |

### 2.5 登录请求的完整流程

```
POST /api/users/login
  Body: { "account": "zhangsan", "password": "123456" }
     │
     ▼
  UserController.login(LoginRequest)
     │
     ▼
  UserServiceImpl.login()
     ├── findByAccount("zhangsan")  → User
     ├── passwordEncoder.matches("123456", user.password)  → true/false
     ├── jwtUtil.generateToken(userId)  → JWT String
     └── updateLastLoginAt(userId)
     │
     ▼
  Response: { code: 200, message: "登录成功",
              data: { userId, username, isAdmin, ... },
              token: "eyJhbGciOiJIUzUxMiJ9..." }
```

## 3. 前端实现

### 3.1 登录 Modal — `LoginModal.tsx`

- 登录表单：支持账号+密码、邮箱+验证码两种模式切换
- 调用 `useLogin` hook 发起请求
- 成功后存储 token 到 Redux store + localStorage
- 关闭弹窗，刷新用户状态

### 3.2 注册 — `useRegister.ts`

- 调用 `POST /api/users` 注册接口
- 成功后自动登录（存储 token）

### 3.3 自动登录流程

```
App 初始化
  → Redux store 中取出 token
    → 如果有 token → 调用 whoami()
      → 成功：刷新 token + 用户信息
      → 失败：清除 token，跳转登录页
    → 如果无 token → 显示未登录状态
```

## 4. 用户表结构 (MySQL)

```sql
CREATE TABLE `user` (
  `user_id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `account` varchar(32) NOT NULL,
  `username` varchar(16) NOT NULL,
  `password` varchar(255) NOT NULL COMMENT 'BCrypt 加密',
  `gender` tinyint DEFAULT NULL,
  `birthday` date DEFAULT NULL,
  `avatar_url` varchar(255) DEFAULT NULL,
  `email` varchar(255) DEFAULT NULL,
  `school` varchar(255) DEFAULT NULL,
  `signature` varchar(255) DEFAULT NULL,
  `is_banned` tinyint NOT NULL DEFAULT '0',
  `is_admin` tinyint NOT NULL DEFAULT '0',
  `last_login_at` datetime DEFAULT NULL,
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `idx_account` (`account`),
  UNIQUE KEY `idx_email` (`email`)
);
```

## 5. 设计要点总结

| 要点 | 说明 |
|---|---|
| 多模式登录 | 账号+密码 / 邮箱+密码 / 邮箱+验证码，三种方式统一入口 |
| BCrypt 加密 | 使用 `BCryptPasswordEncoder` 加密密码，不存储明文 |
| 滑动过期 | `whoami()` 每次调用返回新 token，用户活跃则永不过期 |
| 统一响应 | TokenApiResponse 封装 token，前端无需特殊处理 |
| 事务保护 | 注册流程使用 `@Transactional`，保证账号/用户数据一致性 |
