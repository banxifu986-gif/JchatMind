```
idx_chunk_embedding | CREATE INDEX idx_chunk_embedding ON public.chunk_bge_m3 USING ivfflat (embedding) WITH (lists='100')

idx_user_memory_user_id | CREATE INDEX idx_user_memory_user_id ON public.user_memory USING btree (user_id)

```

- idx_user_memory_candidate_user_id 为契约外冗余索引
