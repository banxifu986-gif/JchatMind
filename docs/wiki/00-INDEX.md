## 按任务选路

- **修一个具体 bug**：00 选模块页 → 模块页"不变量与契约"节 → 对应测试。基线命令见 [01 §启动与校验](01-系统总览与运行边界.md)。
- **新增 REST 接口**：[02 认证鉴权](02-认证鉴权与异步邮件.md)（鉴权三层约定）→ [13 数据模型](13-数据模型与迁移.md)（如需新表）→ 架构文档第 6 节同步。
- **动 RAG 链路**：[07 摄入](07-RAG摄入与索引.md) → [08 检索](08-RAG检索与排序.md) → [14 评测](14-评测体系与门禁.md)（任何通道变更必须升级数据集/索引版本）。
- **动 Agent/工具**：[03 核心循环](03-Agent核心循环.md) → [05 意图](05-意图路由与工具选择.md) → [06 Harness](06-工具Harness.md)（新工具必须走 Harness 代理）。
- **发布/验收判断**：[14 评测体系与门禁](14-评测体系与门禁.md) → 架构文档第 7 节。
- **想改架构级决策**：先读 [16 设计决策与权衡](16-设计决策与权衡.md)，确认不是在推翻已有审查结论。

## 每页固定结构

每页均为：**定位 → 关键文件索引 → 运行链路 → 不变量与契约 → 明确边界 → 配置项 → 验证入口 → 关联文档**。页首标注"最后核对"日期；数字（TTL、阈值、上限）一律来自源码或配置，改动代码必须回填。

## 维护规则

| 代码变化 | 最低文档动作 |
| --- | --- |
| 某模块链路/契约/配置变化 | 更新对应 wiki 页（含"最后核对"日期），同页数字逐一核对 |
| 新增/删除模块级能力（新 Controller、新 queue、新评测层） | 更新对应 wiki 页 + 架构文档第 3/6 节 + 本页模块地图 |
| 总览级变化（能力边界表、技术栈、架构图） | 只更新架构文档与 [01 总览](01-系统总览与运行边界.md)，不扩散 |
| 方案废弃或阶段完成 | 历史细节移入 `docs/archive/`，wiki 页只留结论与归档链接 |

历史结论只从归档区查阅：[../archive/2026-08-15/](../archive/2026-08-15/)、[../archive/2026-11-10/](../archive/2026-11-10/)、[../archive/2026-11-12/](../archive/2026-11-12/)。若归档结论仍然有效，先回填对应 wiki 页，再引用它。
