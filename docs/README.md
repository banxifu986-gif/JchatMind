## 使用顺序

1. 先读 [根 README](../README.md) 了解项目范围、技术栈与启动方式。
2. 再读 [wiki/00-INDEX.md](wiki/00-INDEX.md) 按任务选路，读对应模块页。
3. 全局链路、接口契约与能力边界以 [wiki/01](wiki/01-系统总览与运行边界.md) 与对应模块页为准。
4. 历史结论只从归档区查阅；若仍然有效，先回填对应 wiki 页，再引用它。

## 更新规则

- 某模块链路/契约/配置变化：更新对应 wiki 页（含页首"最后核对"日期）。
- 总览级变化（能力边界表、架构图、接口总表、新增模块）：更新 [wiki/01](wiki/01-系统总览与运行边界.md) 与 [00-INDEX](wiki/00-INDEX.md) 模块地图。
- 已完成或废弃的方案移动到归档区，不在现行文档中保留。
- wiki 与源码矛盾：先核对源码，以更正后的一方为准。
